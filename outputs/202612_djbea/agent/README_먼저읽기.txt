기업지원사업_에이전트 실습 폴더 (교육용 가상 데이터)

이 폴더를 내 컴퓨터에 두고, ChatGPT(Work) 또는 Claude(Cowork) 프로젝트에 연결해 실습함.
모든 기업명·대표자·연락처·금액은 가상(가명) 데이터이며 실제 기관·기업과 관계없음.

00_지침·양식/   공고문.docx, 선정기준.txt, 안내문_양식.docx, 검토기준표.xlsx, 참고_진흥원/
01_신청명단/    참여기업_명단.xlsx (100개사, 가명 처리)
02_신청서류/    신청서 10건 + 4대보험 증빙 PDF (일부 누락·불일치 포함 — 3교시 검토용)
03_실적/        월별·사업별_실적.xlsx (5개 사업, 2026-01~11 — 4교시 분석용)
05_결과물/      에이전트가 만든 버전별 파일 + 변경이력.md 가 저장되는 곳
06_최종/        담당자가 승인한 최종본만 직접 옮기는 곳 (에이전트 저장 금지)

※ 원본 파일은 수정하지 말고, 실습 전에 폴더 전체를 한 번 복사해 두면 언제든 처음부터 다시 할 수 있음.

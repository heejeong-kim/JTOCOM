1

명단과 분류 기준 읽기

1-1같은 실습 폴더에서 시작하기

기업지원사업 프로젝트에 연결한 가상 실습 폴더를 사용합니다. 폴더가 없다면 기업지원사업 에이전트 실습 ZIP을 내려받아 압축을 풀고 연결하세요.

  • 참여기업_명단.xlsx · 접수번호, 소재지, 업력, 근로자 수, 체납 여부, 필수서류 제출 여부, 평가 점수
  • 선정기준.txt · 자격요건, 필수서류 3종, 평가 기준점, 판단 보류 기준
  • 공고문.docx · 안내문_양식.docx · 사업명, 제출 방법, 날짜, 문의처와 안내문 구성

1-2분류 기준 대조하기

판정에 필요한 정보가 비어 있거나 ‘확인 중’이면 담당자가 확인할 수 있도록 먼저 표시합니다. 자격요건은 대전 소재, 업력 1년 이상, 상시근로자 5~99명, 국세·지방세 체납 없음입니다.

분류조건기록할 근거
선정자격 충족, 70점 이상, 필수서류 3종 제출자격·점수·서류 충족
보완자격 충족, 70점 이상, 필수서류 누락제출이 확인되지 않은 서류명
탈락자격 미충족 또는 70점 미만미충족 항목과 해당 원본 값
판단 보류판정에 필요한 값이 비어 있거나 확인 중담당자가 확인할 항목
2

대상별 안내문과 공문 구성

2-1수신자가 해야 할 일을 먼저 쓰기

  • 선정 · 협약서(날인), 사업자 통장 사본, 자부담 확약서를 2026년 12월 18일(금) 18시까지 제출하도록 안내합니다.
  • 보완 · 해당 기업의 누락 서류를 구체적으로 적고, 2026년 12월 11일(금) 18시까지 제출하도록 안내합니다.
  • 미선정 · 내부 분류는 ‘탈락’, 외부 안내는 양식에 맞춰 ‘미선정’으로 씁니다. 안내할 사유는 담당자가 확인합니다.
  • 판단 보류 · 확인할 항목을 내부 검토표에 남기고 이메일·문자 초안 대상에서 제외합니다.

2-2채널별로 정보량 조절하기

안내문·이메일에는 사업명, 접수번호, 결과, 제출 항목·기한·방법, 문의처를 넣습니다. 문자에는 대상이 해야 할 행동과 기한을 먼저 쓰고, 상세 내용은 안내문을 보도록 연결합니다. 내부 검토용 공문에는 목적, 분류별 건수, 후속 일정, 확인 필요 항목과 붙임을 적습니다.

직접 해 보는 업무 실습

실습 1 · 15분Excel 명단 검증부터 100건 분류까지

1교시의 기업지원사업 운영 에이전트에서 새 작업을 엽니다. 샘플 5건을 먼저 대조한 다음 같은 기준을 100건에 적용합니다.

A. 원본 시트와 분류에 쓸 열 확인하기

Excel에서 신청명단 시트를 열어 1행이 머리글이고 2~101행이 데이터인지 확인합니다. 작성 안내 시트는 설명용입니다.

  • A열 접수번호를 비교 기준으로 씁니다. 같은 접수번호가 나오면 원본 행을 유지하고 확인 목록에 기록합니다.
  • D·F·G·H열에서 소재지·업력·근로자 수·체납을, I~K열에서 제출 상태를, L열에서 평가 점수를 확인합니다.
  • 미제출은 확인된 누락입니다. 빈칸·확인 중은 판정에 필요한 값이 확인되지 않은 상태입니다.

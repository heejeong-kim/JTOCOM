1-1생성형 AI의 강점과 한계

생성형 AI(Generative AI)의 중심에는 대규모 언어 모델(LLM, Large Language Model)이 있습니다. 방대한 문장을 학습한 뒤 “다음에 올 가능성이 높은 단어”를 이어 붙여 답을 만듭니다. 그래서 문장은 자연스럽지만, 그 내용이 사실인지는 스스로 보장하지 못합니다.

강점 — 이런 일에 빠릅니다

  • 초안 작성 — 안내문·공문·보고서 초안을 수십 초 안에 여러 버전으로
  • 형식 변환 — 공문 → 문자, 장문 → 표, 메모 → 개조식 보고
  • 요약·추출 — 긴 공고문에서 자격요건·제출서류만 뽑기
  • 분류·정리 — 기준을 주면 명단·문의를 유형별로 나누기

한계 — 이런 점은 사람이 확인합니다

  • 환각(Hallucination) — 없는 규정·날짜·수치를 그럴듯하게 지어냄
  • 내부·최신 정보 부재 — 기관 규정, 올해 공고는 입력해야만 앎
  • 계산 실수 — 긴 표의 합계·비율은 반드시 검산
  • 맥락 누락 — 대화가 길어지면 앞에서 준 조건을 놓침

1-4실무 프롬프트 구조화

AI의 답이 아쉬운 이유는 대부분 정보가 부족해서입니다. 신입 직원에게 업무를 지시하듯 다섯 가지를 빠짐없이 알려 주세요.

역할Role

누구의 입장에서 쓸지
“기업지원사업 담당자로서”

맥락Context

어떤 상황·배경인지
“1차 서류심사 선정 결과”

작업Task

무엇을 해 달라는지
“선정 안내 문자 작성”

형식Format

어떤 모양으로 받을지
“90자 단문 + 장문 1개”

조건Constraint

지켜야 할 규칙
“공문체, 정보 지어내지 않기”

①프롬프트가 좋아지는 4단계※ 민트 표시는 이전 단계에서 새로 더한 부분입니다.

  1. Lv.1요청만어떤 공고문인지 몰라 일반적인 요약 방법을 설명하거나, 그럴듯한 내용을 지어냅니다.

    공고문 요약해

    효과 AI가 대상과 형식을 추측함
  2. Lv.2+ 맥락실제 공고문을 근거로 요약하지만, 요약 길이와 항목이 요청할 때마다 달라집니다.

    아래 붙여 넣은 '2026 청년 일자리 지원사업' 공고문을 요약해.
    {공고문 붙여 넣기}

    효과 대상 문서가 분명해짐
  3. Lv.3+ 형식항목이 고정된 표로 나와 바로 붙여 쓸 수 있습니다. 다만 공고문에 없는 항목은 AI가 임의로 채울 수 있습니다.

    아래 붙여 넣은 '2026 청년 일자리 지원사업' 공고문을 지원대상 / 지원내용 / 신청기간 / 제출서류 / 문의처 5개 항목의 표로 요약해.
    {공고문 붙여 넣기}

    효과 바로 붙여 쓸 수 있는 모양이 됨
  4. Lv.4+ 역할 · 조건근거 없는 항목은 ‘공고문 미기재’로 드러나고, 날짜·금액이 원문 그대로 유지됩니다. 예상 질문까지 함께 나와 문의 응대 준비에 바로 씁니다.

    너는 일자리지원사업 담당자야.
    아래 붙여 넣은 '2026 청년 일자리 지원사업' 공고문을 지원대상 / 지원내용 / 신청기간 / 제출서류 / 문의처 5개 항목의 표로 요약해.
    공고문에 없는 내용은 '공고문 미기재'로 표시하고, 날짜·금액은 원문 표기 그대로 써.
    마지막에 신청자가 자주 물을 질문 3개를 덧붙여줘.
    {공고문 붙여 넣기}

    효과 오류를 막고 활용도까지 높임

업무 자동화 에이전트 만들기

실습 2의 공통 실행 카드를 바탕으로 수강생 모두 각자의 실습 환경에 기업지원사업 운영 에이전트를 만듭니다. 같은 프로젝트에 실습 폴더와 공통 지침을 연결해 2~4교시까지 이어 씁니다.

3-1채팅과 에이전트는 무엇이 다를까?

채팅(Chat)은 질문에 답을 줍니다. 에이전트(AI Agent)는 목표를 받으면 스스로 계획을 세우고, 내 폴더의 파일을 읽고, 결과물 파일을 만들어 저장합니다. 사람은 계획을 승인하고 결과를 검토합니다.

채팅 — 답을 받는다

  • 내용을 매번 복사해 붙여 넣음
  • 결과를 다시 복사해 한글·엑셀에 옮김
  • 대화가 끝나면 조건을 다시 설명해야 함

에이전트 — 결과물을 받는다

  • 연결된 폴더의 파일을 직접 읽음
  • 엑셀·문서 파일을 만들어 폴더에 저장
  • 프로젝트 지침·컨텍스트가 매번 자동 적용

①에이전트를 이루는 4가지

01.지침Instructions

역할, 작업 원칙, 결과물 형식, 하지 말아야 할 일

02.컨텍스트Context

공고문·양식·기준표 등 참고 파일과 링크, 프로젝트 메모리

03.폴더 권한Local folder

읽고 쓸 수 있는 내 컴퓨터의 폴더 — 필요한 폴더만 연결

04.업무 흐름Workflow

계획 → 승인 → 실행 → 결과 저장 → 사람의 검토

7. 결과물은 내려받을 수 있는 XLSX·DOCX로 만들고, 파일 생성이 어려우면 표는 탭 구분 텍스트, 문서는 본문 텍스트로 보여 줘.

9. 결과물은 내가 내려받아 05_결과물에 저장할 거야. 로컬 폴더에 직접 저장했다고 표현하지 마.

1

실적 데이터 구조와 집계 원칙

같은 기업지원사업 운영 프로젝트에서 03_실적/월별·사업별_실적.xlsx를 엽니다. 사업목표·월별실적·작성 안내 세 시트를 확인합니다.

  • 사업목표는 5개 사업의 연간 지원기업·참여인원 목표와 예산입니다.
  • 월별실적은 2026년 1~11월 기록입니다. A열 기준월, B열 사업명, C열 지원기업, D열 참여인원, E열 집행액(백만 원), F열 비고입니다.
  • 월별 지원기업을 더한 값은 월별 기록 합계입니다. 기업 식별자가 없어 고유 기업 수로 단정할 수 없습니다.

보고 기준은 11월 누계이며 달성률은 11월 누계 ÷ 연간 목표입니다. 12월 실적은 포함하지 않고, 빈칸을 0으로 바꾸지 않습니다.

실습 1중복·빈칸부터 확인하기

원본 위치실제 사례확인할 처리
월별실적 34행2026-07 창업 보육 프로그램 · C~E 빈칸집계 지연 · 누락값 유지
월별실적 57행2026-05 청년 일자리 매칭 · 중복 입력 의심동일 월·사업의 기존 행과 대조
전체데이터 56행 / 월·사업 조합 55개중복 후보 1개 조합 · 2개 행 대조

Excel에서 34행 비고를 읽고 57행과 같은 월·사업을 필터로 찾습니다. 두 행의 수치가 같은지 비교하고, 담당자 확인 전에는 원본을 삭제하지 않습니다.

✎ { }로 표시한 부분은 수정할 곳입니다. 채워진 샘플로 바로 실행하거나 내 업무에 맞게 바꿔 사용하세요.

프롬프트
[자료] 월별·사업별_실적.xlsx의 월별실적 시트를 읽어.
[검사] 데이터 행 수, 기준월 범위, 사업 수, 월+사업 중복, C~E 빈칸과 비고를 확인해.
[표] 원본 행 | 월 | 사업 | 문제 | 원본 값 | 확인 질문을 작성해. 34행과 57행을 반드시 원문으로 확인해.
[처리] 원본을 보존해. 강의용 가정으로 ‘중복 의심으로 표시된 57행은 집계에서 임시 제외, 34행 빈칸은 미확정 유지’를 적용할 계획을 보여 주고 내가 승인할 때까지 기다려.
[파일 생성 대안] 파일을 만들 수 없으면 표는 탭으로 구분한 텍스트, 문서는 복사 가능한 본문으로 응답해. Excel A1 또는 문서 편집기에 붙여 넣어 내가 저장할게.

34행: 2026-07 창업 보육 프로그램의 수치 빈칸. 집계 지연으로 확인 필요.
57행: 2026-05 청년 일자리 매칭 중복 의심. 기존 행과 대조 필요.
원본 보존 후 제시한 교육용 처리 가정을 승인받겠습니다.

확인 이 처리 방식은 교육용 가정입니다. 실제 업무에서는 담당자 확인 후 중복·빈칸을 확정합니다.

실습 2사업별 누계·달성률 집계하기

A. 승인한 처리 기준을 집계용 사본에 적용합니다. B. 지원기업·참여인원·집행액을 사업별로 합산합니다. C. 사업목표 시트를 연결해 각각의 비율을 구합니다.

프롬프트
[입력] 승인한 집계 사본과 사업목표를 사업명으로 연결해.
[계산] 사업별 지원기업 누계, 참여인원 누계, 집행액 누계와 각각의 연간 목표·예산 대비 비율을 구해. 월별 합계표도 작성해.
[미확정] 창업 보육 프로그램 7월이 비어 있으므로 해당 사업의 누계·비율은 ‘확인된 값의 잠정 누계’로 표시해. 전체 합계에도 미확정 포함 사실을 적어.
[검산] 월별 총합과 사업별 총합이 같은지 지표마다 확인하고, 목표가 0이거나 비어 있으면 비율을 계산하지 말고 확인 필요로 표시해.
[출력] 05_결과물/20261204_사업실적집계_v1.xlsx의 집계·월별합계·확인사항 시트로 만들거나 복사용 표로 보여 줘. 모든 비율의 계산식을 함께 적어.
[파일 생성 대안] 파일을 만들 수 없으면 표는 탭으로 구분한 텍스트, 문서는 복사 가능한 본문으로 응답해. Excel A1 또는 문서 편집기에 붙여 넣어 내가 저장할게.

지원기업 누계·참여인원 누계·집행액 누계와 각각의 연간 목표를 연결합니다.
창업 보육 프로그램은 7월 빈칸 때문에 확인된 값의 잠정 누계로 표시합니다.
월별 합계와 사업별 합계를 같은 기준으로 검산합니다.

확인 지원기업·참여인원·집행액 단위를 구분하고, 중복 제외와 빈칸 처리 설명이 표에 남아 있어야 합니다.

실습 3차트와 근거 있는 보고 요약 작성하기

집계표에서 사업별 지원기업 달성률 막대차트와 월별 집행액 꺾은선차트를 만듭니다. 차트 기능이 없으면 Excel에서 해당 두 열을 선택해 삽입 → 차트를 사용합니다. 잠정 누계가 포함된 차트에는 주석을 붙입니다.

✎ { }로 표시한 부분은 수정할 곳입니다. 채워진 샘플로 바로 실행하거나 내 업무에 맞게 바꿔 사용하세요.

프롬프트
[자료] 방금 검산한 실적 집계표와 확인사항을 사용해.
[차트] 사업별 지원기업 달성률 막대차트, 월별 집행액 꺾은선차트의 원본 표를 제공해. 제목에 2026년 1~11월과 단위를 적어. 잠정값은 주석으로 표시해.
[보고] 목적·집계 범위 → 주요 실적 3개 → 확인 필요 → 후속 조치 순서로 1쪽 내부 보고 초안을 써. 수치마다 출처 시트와 지표를 표시해.
[조건] 자료에 없는 성과 원인, 사업 효과, 12월 예상 실적은 추정하지 마. 단순 월별 합계를 고유 기업 수로 표현하지 마.
[저장] 05_결과물/20261204_사업실적보고초안_v1.docx로 만들거나 복사 가능한 본문으로 작성해. 별도 보고서 양식은 현재 키트에 없으므로 위 목차를 초안 형식으로 사용해.
[파일 생성 대안] 파일을 만들 수 없으면 표는 탭으로 구분한 텍스트, 문서는 복사 가능한 본문으로 응답해. Excel A1 또는 문서 편집기에 붙여 넣어 내가 저장할게.

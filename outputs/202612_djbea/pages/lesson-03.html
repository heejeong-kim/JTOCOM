3교시

신청서·증빙자료 검토 및 누락 확인

같은 기업지원사업 운영 프로젝트에서 실제 가상 자료를 대조하며 따라 하는 3교시 교안 초안입니다.

목차
  1. 학습목표
  2. 1같은 프로젝트와 제출 기준 확인
  3. 2PDF 주요 정보 추출과 접수목록
  4. 3증빙 대조와 누락·불일치 확인
  5. 4담당자 확인 목록과 보완 요청
  6. 5정리 · 셀프 체크

※ [예시 결과보기]는 교육용 응답 예시입니다. 실제 GPT 실행 결과는 입력 자료와 대화에 따라 달라질 수 있습니다.

학습목표

초안 · 50분 · 자료 확인 8분 → 정보 추출 12분 → 증빙 대조 15분 → 보완 요청 10분 → 정리 5분

1신청서에서 근거를 남기며 주요 정보를 추출함
2접수번호로 원본·명단·증빙을 연결함
3누락·불일치 확인 목록과 보완 요청 초안을 작성함
강사 GPT 시연 → 각자 사용하는 무료 도구로 샘플 따라 하기 → 원본과 함께 확인합니다. 첨부 한도에 도달하면 PDF 텍스트나 Excel의 필요한 행을 복사해 입력합니다.
공통 파일 관리 · 기업지원사업_에이전트 폴더의 원본은 보존하고, 내려받거나 직접 만든 결과물은 05_결과물에 저장합니다. 파일 이름은 20261204_업무명_v1.확장자로 시작하며, 같은 이름이 있으면 v2·v3으로 올립니다. AI가 보여 준 날짜·파일명·버전·바뀐 내용·작성 한 행을 05_결과물/변경이력.md에 기록합니다. 담당자가 검토·승인한 파일만 직접 06_최종으로 옮깁니다.
1

자료와 검토 기준 확인

1교시에서 만든 기업지원사업 운영 프로젝트를 열고 2교시 분류표를 참고합니다. 이번 시간에는 신청서 10건과 4대보험 증빙 8건을 직접 읽어 접수목록을 만듭니다.

  • 02_신청서류의 신청서_2026-DX-001.pdf부터 010.pdf까지 확인합니다.
  • 증빙_4대보험 파일은 001·002·004·005·006·007·008·009의 8건입니다. 003·010은 제공 폴더에서 확인되지 않습니다.
  • 00_지침·양식/검토기준표.xlsx와 선정기준.txt를 열어 비교 항목을 확인합니다.

파일이 없는 상태, 신청서에 ‘미제출’이라고 적힌 상태, 값이 다른 상태를 각각 기록합니다. 이 실습 폴더에는 사업자등록증·재무제표 증빙 PDF가 포함되어 있지 않아 해당 서류의 실제 접수 여부는 담당자가 확인해야 합니다.

실습 1신청서에서 접수목록 만들기

A. 신청서 001과 004 두 파일을 먼저 열고 기업명·근로자 수·신청 금액 위치를 확인합니다. B. 두 건의 표를 AI에게 요청하고 원문과 대조합니다. C. 강사는 10건으로 확대하는 과정을 시연합니다.

✎ { }로 표시한 부분은 수정할 곳입니다. 채워진 샘플로 바로 실행하거나 내 업무에 맞게 바꿔 사용하세요.

프롬프트
[자료] 신청서_2026-DX-001.pdf와 신청서_2026-DX-004.pdf를 읽어.
[추출] 접수번호, 기업명, 대표자, 소재지, 설립일, 근로자 수, 신청 금액(원), 신청서에 적힌 제출 상태, 출처 파일과 페이지를 추출해. 값을 추정하거나 기존 명단으로 덮어쓰지 마.
[표] 접수번호마다 한 행으로 작성해. 미확인 값은 ‘원문 확인 필요’로 표시해. 신청 금액의 자부담 포함 문구도 따로 남겨.
[저장] 확인 후 05_결과물/20261204_접수목록_v1.xlsx로 저장할 수 있게 해.
[파일 생성 대안] 파일을 만들 수 없으면 표는 탭으로 구분한 텍스트, 문서는 복사 가능한 본문으로 응답해. Excel A1 또는 문서 편집기에 붙여 넣어 내가 저장할게.
▤[예시 결과 보기] GPT 응답 샘플

2026-DX-001 · (주)이음테크 · 근로자 15명 · 신청 금액 20,000,000원
2026-DX-004 · (주)늘봄솔루션 · 근로자 18명 · 신청 금액 12,000,000원
출처: 각 접수번호의 신청서 PDF 1페이지.

확인 001은 15명·20,000,000원, 004는 18명·12,000,000원입니다. 두 건이 맞으면 같은 열로 10건을 확인합니다.

실습 2신청서·증빙·명단 대조하기

접수번호원본 확인 사례검토 기록
001신청서 15명 / 증빙 8명 / 명단 8명근로자 수 불일치 · 기준일과 산정 범위 담당자 확인
007신청서 49명 / 증빙 42명불일치 · 두 값과 출처를 모두 보존
005신청서 세종특별자치시 조치원읍 / 명단 대전 대덕구소재지 불일치 · 명단 수정 여부 확인
008신청서 대표508 / 명단 대표008대표자 불일치 · 원문 대조
003·0104대보험 증빙 파일 없음제공 폴더에서 미확인 · 담당자 접수 여부 확인
010신청서에 재무제표 미제출 표기보완 대상 정보 기록

먼저 001의 두 PDF를 나란히 열고 표시된 인원을 비교하세요. 증빙 기준일은 2026-10-31입니다. 다른 기준일의 숫자가 다르다는 이유만으로 허위라고 판단하지 않습니다.

✎ { }로 표시한 부분은 수정할 곳입니다. 채워진 샘플로 바로 실행하거나 내 업무에 맞게 바꿔 사용하세요.

프롬프트
[입력] 접수목록, 같은 접수번호의 신청서·4대보험 PDF, 참여기업_명단.xlsx를 비교해.
[검토] 001·007의 근로자 수, 005 소재지, 008 대표자, 003·010 증빙 파일 존재 여부를 확인해.
[표] 접수번호 | 검토 항목 | 신청서 값·출처 | 증빙 값·출처 | 명단 값·셀 | 상태 | 담당자 확인 질문.
[기준] 상태는 일치·불일치·제공 폴더 미확인·신청서상 미제출·판단 보류로 구분해. 명단과 PDF 값을 보존하고 담당자 승인 전에 수정하거나 적격·부적격을 확정하지 마.
[결과] 05_결과물/20261204_누락불일치검토표_v1.xlsx로 저장 가능한 표를 보여 줘.
[파일 생성 대안] 파일을 만들 수 없으면 표는 탭으로 구분한 텍스트, 문서는 복사 가능한 본문으로 응답해. Excel A1 또는 문서 편집기에 붙여 넣어 내가 저장할게.
▤[예시 결과 보기] GPT 응답 샘플

2026-DX-001 · 신청서 15명 / 증빙 8명 / 불일치
2026-DX-007 · 신청서 49명 / 증빙 42명 / 불일치
담당자 확인: 기준일과 산정 범위 확인 후 처리.
003·010 증빙은 제공 폴더에서 미확인.

확인 파일 미확인과 실제 미제출을 구분하고, 불일치 행마다 양쪽 값과 근거 파일이 있어야 합니다.

실습 3확인 질문과 보완 요청 초안 만들기

A. 검토표에서 담당자가 확인할 항목을 고릅니다. B. 010의 재무제표 미제출 표기로 보완 문안을 만듭니다. C. 검토표와 문안의 접수번호·서류명을 대조합니다.

✎ { }로 표시한 부분은 수정할 곳입니다. 채워진 샘플로 바로 실행하거나 내 업무에 맞게 바꿔 사용하세요.

프롬프트
[입력] 검토표, 안내문_양식.docx의 보완 요청 양식, 선정기준.txt를 사용해.
[내부용] 001 인원 불일치, 003 증빙 파일 미확인에 대해 담당자가 원본 접수 상태와 기준일을 확인할 질문을 작성해.
[외부 초안] 2026-DX-010의 재무제표(최근 1년) 보완 안내를 작성해. 기한은 양식의 2026-12-11(금) 18시와 대조해.
[조건] 제공 폴더에 없다는 이유만으로 추가 제출을 확정하지 마. 외부 발송 전 담당자 검토 항목을 남기고 실제 전송은 하지 마.
[저장] 05_결과물/20261204_보완요청검토초안_v1.docx로 저장할 본문을 작성해.
[파일 생성 대안] 파일을 만들 수 없으면 표는 탭으로 구분한 텍스트, 문서는 복사 가능한 본문으로 응답해. Excel A1 또는 문서 편집기에 붙여 넣어 내가 저장할게.
▤[예시 결과 보기] GPT 응답 샘플

귀사((주)라온물산, 접수번호 2026-DX-010)의 재무제표(최근 1년)가 확인되지 않아 보완을 요청드립니다.
2026년 12월 11일(금) 18시까지 이메일로 제출해 주시기 바랍니다.
발송 전 담당자 접수 상태 확인이 필요합니다.

확인 문안은 담당자가 접수 상태를 확인한 뒤 승인합니다. 같은 프로젝트에 접수목록·검토표를 남깁니다.

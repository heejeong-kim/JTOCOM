생성형 AI 실습 : 영상 + 음악

생성형 AI를 활용한 짧은 영상(10–30초)와 브랜드 무드 음악(10–30초)를 기획–제작–후편집–발표까지 수행하는 전 과정 경험 설계

1. 영상 생성

1) 도구 분류표

카테고리 도구 강점 적합 작업
Text to Video Runway / Pika / Sora 자연스러운 장면 전환, 프롬프트 해석력 콘셉트 영상, 룩북 모션
Image to Video Runway Gen-3, Pika, NanoBanana 스틸 이미지 기반 카메라 워크·패럴럭스 포스터→쇼츠, 제품 모션
영상 편집·합성 CapCut / Premiere Pro(자동 캡션·템플릿) / DaVinci 컷 편집, 자막, 컬러그레이딩 최종 편집·SNS 규격화
음성 합성/내레이션 ElevenLabs / PlayHT 자연스러운 보이스 오버 브랜드 보이스 가이드

2) 제작 워크플로우

  1. 콘셉트 정의: 메시지·톤·타깃 명시 → 1문장 슬로건 수립
  2. 샷리스트: 3–5컷 구성(오프닝–메시지–클로즈) 정의
  3. 프롬프트 초안: 장면별 카메라/조명/스타일 키워드 명시
  4. 생성: 텍스트→영상 또는 이미지→영상 생성
  5. 후편집: 컷 트리밍, 자막, 로고, BGM 싱크 적용
  6. 검수: 해상도·길이·브랜드 일관성 체크리스트 점검

3) 영상 프롬프트 설계 4단계

단계 이름 설명 예시(요약형)
1️⃣ Role 카메라 연출가/아트디렉터 역할 지정 시각 톤·연출 관점 고정 “넌 패션 룩북 감독임. 자연광 데이타임 미니멀 연출 고정”
2️⃣ Style 톤·무드·렌즈·조명 명시 과도한 수식어 지양, 물리 파라미터 병기 “35mm, f/2.8, soft side light, warm daylight”
3️⃣ Content 피사체·동작·배경·소품 구체 명사 + 간단 동사 “패치워크 비니 착용 모델, 흰 벽+우드 스툴, 느린 헤드턴”
4️⃣ Output 길이·비율·프레임·텍스트 플랫폼 규격·표준화 “1080x1920, 24fps, 10–12초, 자막 없음”

4) [실습] 영상 제작 (예 : 7세 이하 유치원생 음원 영상)

a. 컨셉 (세계관, 캐릭터)

🔧 주요 작업

항목 설명 예시 예시
주제(Theme) 동요 내용과 일치하는 시각적 콘셉트 예: 봄소풍, 강아지 친구, 비오는 날 등
컬러 톤(Color Tone) 밝고 따뜻한 파스텔 계열 연노랑, 하늘색, 연두, 복숭아색
시점(Camera POV) 아이 시점 or 동물 시점 “작은 새가 하늘을 날며 친구를 찾아가는 시점”
세계관(Visual World) 3D / 2D / 손그림 스타일 결정 3D Pixar풍 or 수채화풍 일러스트

b. 스토리 작성

🎬 예시1 : 유치원생 음원 + 비디오

구간 시간 가사 내용 시각 구성 감정 포인트
1절 0~10초 “햇살이 쏙, 새싹이 톡!” 잔디 위에서 새싹이 솟고, 햇살이 번지는 장면 설렘
후렴 10~20초 “랄라라 봄이 왔어요~” 동물 친구들이 춤추는 장면 즐거움

🎬 예시2 : 1학년 휴강 에피소드

구간 시간 장면 설명 감정 / 포인트
1막 – 도입 0~3초 📱침대 위, 학생이 자다가 번쩍 눈을 뜬다.시계를 보자 “헉!” 놀라며 이불을 걷어찬다.(알람 꺼진 스마트폰 클로즈업) 긴장, 당황
2막 – 전개 3~7초 🏃‍♂️부랴부랴 옷 입고, 가방 메고 뛰쳐나간다.버스 타는 장면 or 캠퍼스 계단을 전력질주.(카메라 흔들림으로 속도감 표현) 초조, 급박함
3막 – 반전/결말 7~10초 🚪강의실 문을 ‘쾅’ 열자… 아무도 없다.칠판에 “오늘은 휴강입니다 :)” 종이 붙어 있음.학생이 멍하니 웃으며 카메라를 바라본다. 허탈, 웃픔, 자조적인 미소

c. 영상 제작 프롬프트 제작

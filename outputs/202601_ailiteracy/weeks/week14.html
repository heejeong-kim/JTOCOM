학습 목표코딩 지식 없이 AI를 활용한 프로그램 구현

생성형 AI 실습 : 바이브코딩

😎 [참고] 바이브코딩(Vibe Coding)이란?

항목 설명
정의 생성형 AI의 코딩 기능을 활용해 감각적·직관적 코딩 경험을 제공하는 방식. 텍스트 입력만으로 웹, 앱, 게임, 인터랙티브 콘텐츠를 제작할 수 있음.
특징 - 코드 작성보다 ‘아이디어 구현’ 중심
- 비전공자도 접근 가능
- 실시간 미리보기 및 피드백 지원
대표 도구 Cursor, Replit, V0, Claude Projects, Flow (Google), GitHub Copilot 등
핵심 키워드 “No-code + AI + Prompt = 감각적 코딩”

🧩 Vibe Coding 구조 이해

구성 요소 설명 예시
① 프롬프트(명령문) 자연어로 코딩 의도를 전달 “HTML과 CSS로 나만의 프로필 페이지 만들어줘”
”숭의여자대학교 대표 홈페이지 반응형 웹으로 만들어줘”
…
”반려동물 전용 인스타그램을 만들어줘”
② 생성 엔진(LLM) 코드를 분석·생성하는 AI 모델 GPT-5, Claude 3.5, Gemini 등
③ 프리뷰(Preview) 실시간 결과 시각화 웹페이지, 앱 화면, UI 컴포넌트
④ 피드백(Feedback Loop) 코드 수정·반복 개선 “배경색을 파스텔 톤으로 바꿔줘.”

💡 대표 도구별 비교

도구명 주요 특징 강점 활용 예시
Cursor GPT 기반 코드 자동 생성 IDE 코드 품질 높음, 실시간 디버깅 웹앱 제작, 프론트엔드 실습
Replit AI 브라우저 기반 통합 개발 환경 초보자 친화, 배포 용이 포트폴리오 웹사이트, 챗봇 제작
Claude Projects 대화형 문서·코드 협업 기능 구조적 설계, 문맥 유지 PRD + 코드 동시 생성
V0 (Vercel) 프롬프트 → UI 즉시 생성 반응형 웹 자동 생성 스타트업 MVP 제작
GitHub Copilot 실시간 코드 추천 및 자동완성 생산성 극대화 협업형 프로젝트, 유지보수

🧠 Vibe Coding 실습 단계

단계 학습 목표 활동 내용 활용 도구
1️⃣ 아이디어 설계 만들고 싶은 웹/앱 정의 간단한 콘셉트 작성 (예: 나만의 포트폴리오 사이트) Notion, ChatGPT 및 LLM 모델
2️⃣ 프롬프트 작성 코드 생성을 위한 명령어 구성 “HTML+CSS로 프로필 페이지, 이미지 1개 포함” ChatGPT, Claude
3️⃣ 코드 생성 및 테스트 실제 코딩 결과 확인 Cursor/Replit로 실행 Cursor, Replit
4️⃣ UI 수정 및 반복 개선 AI 피드백 반영 “폰트를 좀 더 둥글게”, “배경 밝게” 등 Cursor, V0
5️⃣ 결과 발표 결과물 공유 및 시연 완성된 웹/앱 데모 시연 Replit 링크 공유

생성형 AI 실습 : Text, 이미지

😶‍🌫️ [참고] GPTs 활용법

항목 설명
ChatGPT 일반 사용자용 범용 AI 대화 모델
GPTs (Custom GPT) 특정 목적에 맞게 ChatGPT를 맞춤 설정(Customize) 한 버전
GPTs는 ChatGPT의 상위 개념이 아님 → “맞춤형 버전”‘
Create a GPT’ 버튼은 ChatGPT Plus 사용자만 가능

핵심구조

구성 요소 설명 예시
① 이름 & 설명(Name & Description) GPT의 정체성을 정의 예: “AI 코딩 도우미”, “영어 프레젠테이션 첨삭 GPT”
② 지침(Instructions) GPT의 역할, 말투, 작업 범위 등을 규정 “너는 대학생 멘토야. 명사형 어미로 답해.”
③ 지식 파일 업로드(Files) GPT가 참고할 문서, 데이터, 매뉴얼 추가 예: 회사 제품 매뉴얼, 강의 교안 PDF
④ 도구 설정(Actions) 웹 검색, 코드 실행, API 연결 등 기능 활성화 예: “Web browsing ON”, “Python 활성화”

💡 GPTs 생성 예시

“대학생 팀프로젝트 코치 GPT”

  • 이름: TeamProject Coach
  • 지침: “너는 대학생의 팀프로젝트 멘토야. 학생의 아이디어를 분석하고, PRD와 KPI를 작성하도록 도와줘. 모든 문장은 명사형으로 마무리해.”
  • 업로드 파일: PRD 템플릿.pdf
  • 도구: Web / Python 활성화
  • 테스트 질문: “친환경 앱 아이디어를 MVP로 정리해줘.”

🧱 지침(Instruction) 구성 4단계

단계 이름 설명 예시
1️⃣ Role (역할 설정) GPT가 어떤 전문가로 행동할지 정의 “너는 대학의 컴퓨터공학 교수야.”
2️⃣ Tone & Style (어조/스타일) 문체나 말투를 명시 “전문적이지만 이해하기 쉽게, 명사형 어미로 마무리해.”
3️⃣ Input & Output (입력/출력 구조) 사용자 입력 형식과 GPT의 답변 형식 지정 “사용자의 질문을 표로 정리해 답해.”
4️⃣ Limits (제한 조건) GPT가 하지 말아야 할 행동이나 범위 “정치적 발언 금지, 허위정보 생성 금지.”

💬 예시: PRD 도우미 GPT 지침문

너는 IT 제품 기획을 가르치는 대학 교수야.

학생들이 작성한 아이디어를 분석해 문제 정의, 솔루션, KPI, 기능 구조로 정리해줘.

모든 문장은 명사형 어미로 마무리하고,

표를 사용해 시각적으로 명확하게 표현해.

단, 불확실한 정보는 추정하지 말고 “추가 데이터 필요”로 표시해.

🧠 1. 글쓰기

목표: 구조적 글쓰기, 초안 생성, 어조·톤 조정, 스타일 맞춤

추천 AI 주요 특징 활용 예시
ChatGPT (GPT-5) 문체 조정·서사적 흐름에 강함. 장르별 글쓰기 (에세이, 기사, 스크립트 등) 논설문, 블로그 포스팅, 유튜브 스크립트, 웹툰 대사
Claude 3.5 Sonnet 긴 문맥 유지, 인문학적·창의적 글에 강함 소설, 인터뷰 원고, 인사이트 에세이
Notion AI 실시간 편집·요약, 협업 중심 글쓰기 팀 문서 초안, 회의록, 보고서 초안
Jasper AI 마케팅 카피, 브랜딩 중심 문체 SNS 광고문, 랜딩페이지 문안

🧠 2. 리서치

목표: 빠르고 정확한 정보 수집·정리, 인사이트 도출

추천 AI 주요 특징 활용 예시
Perplexity AI 웹 기반 실시간 검색, 출처 명시 정확 산업 트렌드, 논문 요약, 경쟁사 분석
ChatGPT (with web access) 종합 리서치·분석·요약 가능 시장 보고서 정리, 정책 리서치
Scite.ai / Elicit 논문·학술 자료 리서치 자동화 연구 기반 근거 수집, 학술 요약
Felo AI / Flow AI 최신 웹·SNS 트렌드 리서치 실시간 이슈 분석, 트렌드 맵 제작

🧠 3. 문서 작업

목표: 기획서, 보고서, 슬라이드 등 포맷 완성도 높은 문서 생성

추천 AI 주요 특징 활용 예시
Gamma.app 텍스트 입력 → 자동 프레젠테이션 변환 발표 자료, 프로젝트 제안서
Tome AI 슬라이드 스토리텔링 자동 구성 피치덱, 강의 슬라이드
ChatGPT + Notion / Docs 통합 포맷 기반 문서 자동화 기획서, 회의록, PRD, UT 문서
Canva Magic Write 시각요소 포함된 문서 자동 완성 포스터, 리포트 디자인

🧠 4. 아이디어 도출하기

목표: 브레인스토밍, 콘셉트 기획, 신규 서비스 발상

추천 AI 주요 특징 활용 예시
ChatGPT (GPT-5) 구조화된 아이디어 발상, SCAMPER·SWOT 활용 신사업 기획, 콘텐츠 콘셉트
Gemini 2.0 (Google) 멀티모달 분석, 시각자료 기반 아이디어 이미지·영상 기반 아이디어 확장
Miro AI / FigJam AI 협업형 브레인스토밍 도구 팀 아이디어 워크숍, 키워드 맵핑
Runway / Leonardo AI / Ideogram AI 시각적 아이디어 구현 서비스 콘셉트 시각화, 브랜드 시안

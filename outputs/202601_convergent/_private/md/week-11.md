## 11주차. 컷별 이미지 제작 1
### 🎯 수업 목표
- **학습 목표:** 10주차에서 확정한 등장인물 캐릭터 이미지와 스타일 가이드를 바탕으로, **전체 컷의 1차 시안**을 완성하고 일관성 결함을 식별함
- **핵심 키워드:** 대량 생성(Batch Generation), 일관성 검증(Consistency Audit), 반복 개선(Iteration), 자산 관리(Asset Management)
---
# 0. 들어가며 — 양보다 일관성, 일관성보다 완결성
> 이미지 제작시 "샘플 1장으로 스타일 잠금"이었다면, 이번주차는 "잠근 스타일을 5씬에 동일하게 입혀보기"
> 금주 이후는 변형·후처리·디테일을 다루므로, 11주차는 **"빠르게, 그러나 일관되게, 끝까지"** 가 원칙
- 흔한 실패 패턴 미리 짚기:
  - ① 한 컷에 매달려 5씬을 못 끝냄 → "컷당 최대 시도 횟수" 제한 필요
  - ② 매 컷마다 새 프롬프트 작성 → "스타일 블록 복붙" 규칙 미준수
  - ③ 결과물이 폴더 곳곳에 흩어짐 → "자산 관리 규칙" 부재
---

# 2. 자산 관리 규칙 (Asset Management)
**"기획자도 개발자처럼 파일을 관리한다"** — 12~14주차 웹 구현 시 파일명 정리가 안 되면 작업이 멈춤
### 2-1. 폴더 구조
```text
my_story/
├── 01_reference/        ← 캐릭터 시트, 무드보드
├── 02_cuts_v1/          ← 11주차 1차 시안 (이번 주)
├── 03_cuts_v2/          ← 12주차 보정본 (다음 주)
├── 04_final/            ← 13주차 웹 적용본
└── prompts.md           ← 모든 프롬프트 기록
```
### 2-2. 파일명 규칙
- `{컷ID}_{씬ID}_{버전}.png` 형식
- 예시: `C01_S1_v1.png`, `C02_S3A_v1.png`
- 이유: 파일명만 봐도 어떤 씬·어떤 분기인지 식별 가능 → 11주차에 5컷, 14주차에 50컷이 되어도 검색 가능
### 2-3. 프롬프트 로그(prompts.md)
컷별로 다음 4가지를 기록함

<tr><td>컷 ID</td><td>C01</td></tr>

# 3. 1차 시안 작업 절차 (Workflow)
> 컷별 이미지 제작 소요 시간 확인 후 시간 소요 예측
### 3-1. 컷 1장 생성 사이클 (한 컷 = 5단계)
1. **프롬프트 조립**: 10주차 4 Block 프레임의 ②Scene 블록만 컷별로 교체
2. **1차 생성**: 도구 1개 선택, 1장 출력
3. **즉시 평가**: ○/△/× 판정
4. **재생성 또는 채택**: △는 1회 재시도, ×는 키워드 1개만 교체 후 1회 재시도
5. **저장 + 기록**: 파일명 규칙대로 저장
### 3-2. 즉시 평가 3대 기준
<table header-row="true">
<tr><td>기준</td><td>판정 질문</td><td>× 판정 시 조치</td></tr>
<tr><td>**캐릭터 일관성**</td><td>레퍼런스 시트와 같은 인물로 보이는가?</td><td>캐릭터 키워드(머리, 의상) 강화</td></tr>
<tr><td>**스타일 일관성**</td><td>다른 컷과 같은 화풍·색감인가?</td><td>③Style 블록 누락 키워드 보충</td></tr>
<tr><td>**씬 적합성**</td><td>데이터 딕셔너리 변수값을 시각적으로 표현하는가?</td><td>②Scene 블록의 분위기 키워드 교체</td></tr>
</table>
### 3-3. 시간 박스(Time Boxing) 규칙
- **1컷 최대 3회 시도** — 3회 안에 안 나오면 일단 가장 나은 버전을 v1으로 저장하고 다음 컷으로 진행
- 이유: 12-13주차에 보정·재작업 시간이 별도로 있음. 한 컷에 매달리면 전체 일정 딜레이됨
- 예시: 'NEO-KONGJI 2099' C03(시스템 발각 장면)이 안 풀린다고 해도, v1을 채택 후 12-13주차에 색감 보정으로 위기감을 살리는 방식이 가능함

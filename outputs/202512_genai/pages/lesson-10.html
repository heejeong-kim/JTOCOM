오프닝 스토리 – “민지는 매일 같은 일을 하고 있었다”

아침 9시 15분.

회사원 민지는 또다시 팀 회의 녹음을 틀어놓고 있었다.

회의 끝나면 늘 같은 루틴이 반복된다.

녹음 들으면서 타이핑.

중요 문장 표시.

팀장 버전으로 문장 다듬기.

카톡으로 요약본 보내기.

Notion에도 따로 정리하기.

민지는 마음속으로 중얼거린다.

“이걸 하루에 몇 번을 반복하는 거지…?”

그러다 어느 날, 동료가 무심하게 한마디 한다.

“그거 자동화해봤어? 파일만 올리면 회의록 → 요약 → 팀장 버전 → 카톡 공유까지 한 번에 되는데?”

민지는 반신반의하며 파일을 올려본다.

몇 초 뒤, 화면에 자동 생성된 요약과 정리본이 올라온다.

그 순간 민지는 깨닫는다.

“아… 자동화는 ‘어떤 기능을 쓰는지’가 아니라

내가 매일 반복하던 흐름을 하나로 묶는 거였구나.”

이 짧은 경험이 오늘 우리가 배울

AI 워크플로우 자동화의 출발점이다.

학습목표

  • 반복 업무를 자동화하는 기본 개념 이해
  • 체인(Chain)과 에이전트(Agent)의 차이 이해
  • 초보자도 활용 가능한 자동화 도구의 흐름과 구성 방식 이해
  • 간단한 자동화 실습 흐름을 따라 하며 작동 원리를 체험

1) 워크플로우(Workflow) 자동화 개념

  • AI 자동화는 사람이 매번 반복하던 일을 버튼 한 번으로 끝나는 흐름으로 묶어두는 기술
  • 작업을 작은 단계로 나누고, 그 단계를 자연스럽게 이어 사용자가 중간에 손 댈 필요가 없게 만드는 개념

2) 자동화의 기본 구조

핵심 구조

  • 반복 작업을 작은 단계로 분해
  • 단계들을 앞뒤로 연결해 하나의 흐름 구성
  • 파일 업로드나 버튼 클릭으로 자동 실행
  • 사용자는 중간에 개입 필요 없음

기초 예시

  • 음성 파일 업로드 → 텍스트 변환 → 핵심 내용 정리

중간 예시

  • 회의 녹음 업로드 → 텍스트 변환 → 쟁점 분류 → 날짜별 저장

응용 예시

  • 녹음 → 텍스트 → 요약 → 팀장 말투 보고서 작성 → 카톡 전송 → 일정 등록

3) 체인(Chain)과 에이전트(Agent)의 차이

자동화를 설계할 때 가장 중요한 구분 두 가지 초급자들이 가장 많이 헷갈리는 부분

체인 vs 에이전트

구분 체인 (Chain) 에이전트 (Agent)
비유 세탁기 표준 코스 유능한 집사
특징 정해진 순서대로 무조건 실행
(세탁 → 헹굼 → 탈수) 		상황을 보고 스스로 판단하여 행동
(비 오면 창문 닫고, 배고프면 식사 준비)
장점 결과가 일정하고 예측 가능함 복잡하고 변수가 많은 일 처리에 강함
예시 번역 → 교정 → 저장 "이번 주 여행 계획 짜줘" (검색, 예약, 날씨 확인을 알아서 수행)

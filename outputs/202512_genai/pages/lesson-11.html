1. Text 실습

오프닝 스토리 – “손보다 프롬프트가 빨라야 하는 이유”

밤 11시, 마감 12시간 전. 대학생 수연은 리포트, PPT, 신청서까지 세 가지 과제 앞에서 절망하고 있었습니다. 급한 마음에 AI에게 "이것 좀 정리해줘"라고 던졌지만, 돌아온 건 팀플에도, 교수님께도 낼 수 없는 밋밋한 요약뿐이었죠.

그제야 수연은 깨닫습니다. "아, 그냥 '해줘'가 아니라 '누구에게, 어떻게'를 말해야 하는구나."

그녀는 프롬프트를 다시 설계합니다.
"팀플용 PPT 7장 분량으로, 대상은 1학년이니 쉽게, 하지만 교수님 제출용은 격식 있게."

순식간에 용도별로 완벽하게 갈라진 문서들이 모니터에 뜹니다. 수연은 키보드 위에서 중얼거립니다.
"이제는 글을 직접 쓰는 '손이 빠른 사람'이 아니라, AI를 설계하는 '프롬프트가 빠른 사람'이 이기는 시대구나."

학습목표

  • LLM 작동 원리 이해 및 Role·Context·Task 등 프롬프트 핵심 요소의 정교한 활용
  • 기획·초안·윤문·리서치·슬라이드 제작 등 목적별 AI 텍스트 실무 활용 역량 습득
  • 비판적 팩트체크와 톤앤매너 보정을 통한 인간 주도의 완성도 높은 결과물 창출

1) LLM(거대 언어 모델) 개념 정의

  • LM은 한마디로 “엄청나게 많은 글을 읽고 다음에 올 말을 예측하는 초거대 언어 엔진”이라는 개념
  • 우리가 말한 문장의 다음 단어가 무엇이 자연스러운지 계속 추측해서 문장을 이어가는 기술로 이 과정이 가능한 이유는 뉴스, 책, 블로그, 기술 문서 등 수많은 텍스트에서 패턴을 학습한 모델이기 때문
  • LLM은 명령을 규칙으로 이해하는 것이 아니라 방대한 패턴을 기반으로 ‘그럴듯한 문장’을 생성하는 방식으로 작동하는 구조
  • 우리가 프롬프트에서 “출처 제시”, “모르면 모른다고 말하기”, “톤 지정” 같은 조건을 넣는 이유는 이 예측 과정이 너무 자유로워서 오류나 과장 표현이 나올 수 있기 때문

활용 예시

기초 : 카카오톡 말투로 일정 요약해줘 → 카톡 패턴을 찾아 그대로 적용하는 구조

중간 : 회의 내용을 3줄 팀장 톤으로 정리해줘 → 요약 패턴 + 팀장 말투 패턴 조합

응용 : 포트폴리오 사이트의 About Me를 차분하고 전문적인 톤으로 작성해줘 → 구조 패턴 + 톤 패턴 생성

2) 프롬프트 엔지니어링 요소

[참고] 4요소

요소 의미 역할 예시
Role AI가 수행해야 하는 역할 정의 답변의 톤과 전문성을 결정 “너는 IT 전략 컨설턴트야.”
Context 배경 정보·상황·조건 설명 상황에 맞는 정확한 답변을 유도 “우리 회사는 스타트업이고 AI 도입을 논의 중이야.”
Format 출력 형식과 표현 방식 지정 결과물을 원하는 틀로 구조화 “표로 정리해줘.” “Bullet 5개로 정리해줘.”
Task 실제로 해달라는 일의 내용 핵심 목표·작업 정의 “AI 도입 시 고려해야 할 ROI 항목을 정리해줘.”

[참고] 7요소

  • “한 번 짜서 내가 혼자 쓸 땐” → 7요소가 오버일 수 있음
  • “팀/학생/클라이언트/자동화에서 반복해서 쓸 땐” → 거의 필수에 가까움. 왜냐면, 최신 모델들이 “센스 있게” 만드는 건 맞지만 변동성(variance)이 있음
요소 의미 역할 예시
Role AI의 관점·전문성·말투를 정하는 설정 답변의 톤·깊이·관점을 통제 “너는 IT 전략 컨설턴트야.”
Few-shot 따라야 할 패턴·구조·형식을 예시로 제공 출력의 일관성과 정확도 향상 “아래 예시처럼 표 형식으로 정리해줘.”
ToT (Tree-of-Thought) 여러 단계·여러 가지 관점으로 사고하게 하는 구조 깊은 추론과 논리적 판단 유도 “N가지 관점에서 비교하고 가장 합리적인 이유를 설명해줘.”
Self-Reflection AI가 자신의 답을 스스로 검토·개선하게 하는 구조 논리적 오류와 누락 감소 “전문가 관점에서 다시 검토하고 보완한 버전을 제안해줘.”
Meta Prompt 상위 레벨 전문가 모드로 사고하게 하는 설계 전체 품질·구조·깊이 향상 “너는 세계 최고의 프롬프트 엔지니어이자 XX 전문가야.”
RAG
(Retrieval-Augmented Generation) 		AI가 학습 데이터 외의 외부 정보(검색, 문서)를 참조하도록 기능을 호출 최신성·정확성·사실성 강화 “최신 인터넷 정보 기반으로 정리해줘.”
Agent AI가 스스로 계획을 세우고 도구(브라우저, 코드 실행기 등)를 사용해 작업을 수행 외부 정보 연계와 실제 실행력 강화 “00 사이트 데이터를 수집해 분석한 뒤 보고서를 작성해줘.”

[참고] 7요소 - 답변의 품질과 논리력을 높이기

  • 정확도와 스타일 제어 (Control)
    • Role: 전문가의 관점을 빌려 답변의 품질 상향
    • Few-shot: 예시를 통해 실행 의도와 형식을 명확히 전달
  • 복잡한 문제 해결과 논리 (Logic)
    • ToT (Tree-of-Thought): 여러 해결 경로를 탐색하여 최적의 답 도출
    • Self-Reflection: 스스로 비판하고 수정하여 오류 최소화
    • Meta Prompt: 최적의 프롬프트를 구조적으로 설계하는 상위 기술
  • 한계 돌파와 시스템 확장 (System)
    • RAG: 최신 정보와 외부 데이터를 연결하여 지식 확장
    • Agent: 계획 수립부터 도구 사용까지, 자율적으로 행동하는 AI

구체적일수록 기하급수적으로 향상되는 결과물 품질

  • 구체성 (Specific): 모호한 형용사 대신 명확한 명사 사용
    • (X) "멋진 로고" → (O) "미니멀한 스타일의 흑백 벡터 로고"
  • 제약 조건 (Constraints): 분량 및 형식의 통제
    • (X) "짧게 써줘" → (O) "공백 포함 50자 이내, 3개 리스트업"
  • 톤앤매너 (Tone): 답변의 어조(Tone) 지정
    • (X) "설명해줘" → (O) "유치원생도 이해 가능한 친절하고 유머러스한 말투"

다음 문장을 프롬프트 7요소(Role, Few-shot, ToT (Tree-of-Thought), Self-Reflection, Meta Prompt, RAG (Retrieval-Augmented Generation), Agent) 로 확장해서 프롬프트 작성해줘
“AI 시대 대학생의 경쟁력에 대해 설명해줘”

결과

[Role]

당신은 2025년 한국 대학생의 AI 활용 역량을 연구하는 고등교육·AI 교육 전문가입니다.

[Task]

AI 시대에 대학생이 갖추어야 할 핵심 경쟁력을 설명해 주세요.

[Few-shot: 예시 포함]

예시 작성 방식(형식 따라 작성)

  • 트렌드: 생성형 AI 일상화 → 문제 정의 능력의 중요성 강화
  • 경쟁력: 데이터 리터러시 + AI 프롬프트 능력 + 기획력
  • 실천: 대학생이 이번 학기 내 실천할 수 있는 3가지 행동 제안

[ToT: 사고 분기 요구]

아래 3단 사고 구조로 단계별로 답변하세요.

1단계: AI 시대 취업 환경 변화 분석

2단계: 대학생 경쟁력 TOP 6 도출

3단계: 실천 가능 전략 제시(체크리스트)

[Self-Reflection]

마지막에 자체 검증 3항목을 넣어 답변 품질을 점검하세요.

  • 사례가 포함되었는가?
  • 실천 전략이 구체적인가?
  • 한국 맥락(취업 시장/교육 환경)이 반영되었는가?

[Meta Prompt]

독자가 초보자라고 가정하고, 전문 용어는 짧게 정의하며, 핵심 개념은 비유를 활용해 쉽고 명확하게 설명하세요.

[RAG: 정보 회수 기반 요구]

2024~2025년 기준 한국 취업 시장 또는 AI 도구 활용 관련

공식 보고서·통계 1개 이상을 기반으로 작성하고,

출처 형식으로 표기하세요.

(e.g., “출처: 고용정보원 2024”)

[Agent]

추가로 필요한 데이터가 있다고 판단되면 스스로 검색 질의 문장(가상)을 제시하고,

그 결과를 정리해 답변에 반영한 형태로 제시하세요.

출력 형식(고정)

  1. AI 시대 취업 환경 변화 (요약, 3~5줄)
  2. 대학생 경쟁력 6가지
    • 각 항목: 정의 + 사례 + 적용 학과 예시
  3. 실천 전략 체크리스트(5가지)
  4. 자체 검증(Self-Reflection) 3항목

AI 시대 대학생의 경쟁력에 대해 설명해줘

결과

AI 시대 대학생의 핵심 경쟁력은 크게 5가지로 정리할 수 있음

1. AI 도구 활용 능력

단순히 ChatGPT를 쓰는 것을 넘어, 업무에 맞는 AI 도구를 선택하고 효과적으로 사용하는 능력

예시: 마케팅 과제를 할 때

  • 기존: 직접 자료 조사 → 보고서 작성 → 디자인 (3일 소요)
  • AI 활용: Claude로 시장 분석 → Midjourney로 비주얼 제작 → Canva로 최종 편집 (1일 소요)

중요한 건 AI가 만든 결과물을 검증하고 개선하는 능력

2. 문제 정의 능력

AI는 주어진 질문에 답하지만, 진짜 문제가 무엇인지는 사람이 찾아내야 함

예시: 앱 개발 프로젝트에서

  • 잘못된 질문: "예쁜 UI 만들어줘"
  • 올바른 질문: "60대 사용자가 약 복용 시간을 놓치지 않게 하려면 어떤 UI가 필요할까?"

0. 분석 대상 이해하기

국정ON은 관심 정책 관련 회의 발언을 확인하고 보고서로 정리하는 국정 모니터링 서비스이다.

앞선 답변의 분석 내용을 재구성한 교안이다. 특정 보고서 내용, 실제 시각적 배치, 서버·DB·API 구현은 미확인이다. 아래 도식과 실습은 학습용이며 실제 서비스와 연결되지 않는다.

9. 전체 과정 연결하기

사용자가 관심 키워드 등록 → 프론트엔드에서 입력값 확인 → 서버 및 데이터 저장 공간에서 발언 수집·키워드 비교 → 관련 발언과 알림 결과 표시 → 개발자 도구로 오류 점검 및 배포

실제 내부 처리 방식이 아니라 기능을 기반으로 재구성한 구현 흐름이다.

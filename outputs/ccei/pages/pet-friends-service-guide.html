분석 대상: 펫프렌즈 모바일 웹사이트

펫프렌즈는 반려동물을 키우는 사람들이 필요한 사료, 간식, 생활용품 등을 찾아보고 구매하는 쇼핑 서비스입니다.

서비스를 만드는 사람들은 하나의 웹사이트를 볼 때 단순히 디자인만 보는 것이 아니라, 다음 다섯 가지 관점에서 분석합니다.

이 다섯 가지를 순서대로 분석하면 나중에 직접 웹사이트나 앱을 만들 때 무엇을 준비해야 하는지 이해할 수 있습니다.

※ 확인 범위: 공식 사이트의 상품 분류, 상품 목록, 첫구매 할인 페이지는 확인했습니다. 다만 요청하신 메인 페이지는 웹 조회에서 화면 배치와 메뉴가 정상적으로 추출되지 않았습니다. 따라서 직접 확인하지 못한 화면 구성과 내부 작동 방식에는 [추측]이라고 표시했습니다.

2. 어떤 메뉴와 페이지들이 있을까?

5. 버튼을 누르면 눈에 보이지 않는 뒤쪽에서는 어떤 일이 일어날까?

전문 용어: 서비스 로직(Service Logic) / 기능 처리 흐름

사용자가 어떤 행동을 했을 때 서비스가 어떤 순서와 규칙으로 일을 처리해야 하는지 정하는 것입니다.

예를 들어 식당에서 손님이 음식을 주문하면 직원이 주문을 받고, 주방에서 음식을 만들고, 다시 손님에게 전달합니다. 웹사이트에서도 비슷한 일이 일어납니다.

사용자가 보는 화면은 프론트엔드, 뒤에서 일을 처리하는 곳은 백엔드, 상품과 회원 등의 정보를 보관하는 곳은 데이터베이스라고 합니다.

아래는 일반적인 쇼핑 서비스의 작동 원리를 적용한 설명입니다. 실제 펫프렌즈의 내부 시스템은 공개 화면만으로 확인할 수 없으므로 모두 [추측]에 해당합니다.

사례 ① 상품 목록에서 상품 하나를 눌렀을 때

1. 상품 선택

사용자가 원하는 사료의 사진이나 이름을 누른다.

2. 정보 요청

화면이 서버에 해당 상품의 정보를 보내 달라고 요청한다.

3. 상품 정보 조회

서버가 데이터베이스에서 상품명, 가격, 설명 등의 정보를 찾는다.

4. 정보 전달

서버가 찾아낸 상품 정보를 다시 화면에 전달한다.

5. 상품 상세 화면 표시

사용자가 상품의 사진, 가격, 설명 등을 볼 수 있게 된다.

이러한 정보 요청과 응답을 주고받는 연결 규칙을 API(Application Programming Interface)라고 합니다.

6. 오늘 배운 서비스 기획·개발 용어 총정리

화면을 구성할 때 사용하는 용어

용어쉬운 뜻
레이아웃(Layout)화면의 공간을 나누고 배치하는 방법
헤더(Header)화면의 가장 위쪽 영역
검색창(Search Bar)원하는 정보를 입력하고 찾는 곳
탭(Tab)여러 정보 영역을 전환하는 버튼형 메뉴
GNB(Global Navigation Bar)서비스의 주요 메뉴 모음
메인 배너(Main Banner)주요 행사나 정보를 크게 보여 주는 영역
퀵 메뉴(Quick Menu)자주 사용하는 기능으로 빠르게 이동하는 메뉴
콘텐츠 영역(Contents)실제 정보를 보여 주는 공간
상품 카드(Product Card)상품 하나의 정보를 작은 영역에 묶어 보여 주는 것
하단 메뉴(Bottom Navigation)화면 아래에 배치된 주요 이동 메뉴

메뉴와 이용 순서를 설계할 때 사용하는 용어

용어쉬운 뜻
정보구조도(IA)서비스의 전체 메뉴와 정보의 계층을 정리한 설계도
뎁스(Depth)메뉴가 얼마나 깊이 들어가는지를 나타내는 단계
필터(Filter)원하는 조건에 맞는 정보만 골라 보여 주는 기능
사용자 흐름도(User Flow)사용자가 목적을 달성하기까지 거치는 화면의 순서

화면에 들어갈 정보를 설계할 때 사용하는 용어

용어쉬운 뜻
데이터 구조(Data Structure)정보를 구성하고 조직하는 방법
데이터 정의(Data Definition)어떤 정보를 어떤 형식으로 관리할지 정하는 것
데이터 타입(Data Type)정보가 글자, 숫자, 날짜 등 어떤 종류인지 나타내는 것
문자열(String)글자로 이루어진 정보
숫자(Number)계산할 수 있는 숫자 정보
날짜(Date)특정 날짜를 나타내는 정보
참·거짓(Boolean)예 또는 아니요로 구분되는 정보
이미지(Image)사진이나 그림 정보

기능이 작동하도록 만들 때 사용하는 용어

용어쉬운 뜻
서비스 로직(Service Logic)서비스가 어떤 순서와 규칙에 따라 일을 처리하는지 정한 것
프론트엔드(Frontend)사용자가 직접 보고 조작하는 화면 부분
백엔드(Backend)화면 뒤에서 실제 기능과 정보를 처리하는 부분
서버(Server)사용자의 요청을 받아 필요한 일을 처리하고 결과를 보내는 시스템
데이터베이스(Database)서비스에 필요한 정보를 체계적으로 저장하고 관리하는 공간
API서로 다른 프로그램이 정보나 기능을 주고받기 위한 연결 규칙
조건 로직(Conditional Logic)상황에 따라 서로 다른 행동을 수행하도록 정한 규칙
순서도(Flowchart)일이 처리되는 순서와 판단 과정을 그림으로 나타낸 것

함께 실습

저장하고 되돌리기

2.1 잘 되면 저장, 안 되면 되돌리기

2교시에 해 본 저장·되돌리기를 기능마다 반복함. 기능을 더하기 전에 저장해 두면 망가져도 바로 돌아올 수 있음.

  1. ① 지금 상태 저장하기

    지금 프로젝트 상태를 저장해 두고 싶어.
versions 폴더 안에 {예: 01-데이터연결} 이름의 폴더를 만들고, 지금 파일들을 복사해줘.
versions 폴더 자체와 .env 파일은 복사하지 말아줘.

  2. ② 안 되면 되돌리기

    방금 바꾼 내용이 마음에 들지 않아.
versions/{돌아갈 저장 이름} 상태로 되돌려줘.
되돌리기 전에 지금 상태도 versions에 '되돌리기전' 이름으로 저장하고, 무엇이 바뀌는지 먼저 알려줘.
심화 · Git으로 저장하기

깃(Git)은 저장 지점을 자동으로 기록하는 도구임. "이 폴더에서 Git을 시작하고 지금 상태를 저장해줘. Git이 없으면 설치 방법부터 알려줘."라고 요청하면 됨. 설치에 관리자 권한이 필요할 수 있음.

핵심 기능을 더하기 전에 저장하면 실패해도 겁낼 필요가 없음.

함께 기능 더하기

3.1 함께 더할 기능 3가지

  1. ① 검색

    기능 하나만 만들어줘.
기능 이름: 검색
사용자 행동: 목록 위 검색창에 단어를 입력함
기대 결과: 사업명이나 지원 내용에 그 단어가 들어간 카드만 보임
확인 방법: "시제품"을 입력하면 카드 수가 줄어들고, 없는 단어면 안내 문구가 나옴
다른 기능은 건드리지 말고, 다 만들면 내가 확인할 순서를 알려줘.

  2. ② 마감일 순 정렬

    기능 하나만 만들어줘.
기능 이름: 마감일 순 정렬
사용자 행동: '마감 임박 순' 버튼을 누름
기대 결과: 접수 마감일이 가까운 사업부터 보이고, 카드에 'D-7'처럼 남은 날짜가 보임
확인 방법: 버튼을 누르면 맨 앞 카드의 마감일이 가장 빠름
다른 기능은 건드리지 말아줘.

  3. ③ 상세 보기

    기능 하나만 만들어줘.
기능 이름: 상세 보기
사용자 행동: 카드를 누름
기대 결과: 화면 가운데 팝업(모달, Modal)에 사업의 모든 정보가 보이고, 닫기 버튼과 바깥 클릭으로 닫힘
확인 방법: 아무 카드나 눌러 팝업이 열리고 닫히는지 봄
다른 기능은 건드리지 말아줘.
  • 기능 하나가 끝날 때마다 새로고침해서 확인 방법대로 눌러 봄
  • 잘 되면 2.1 ①로 저장하고 다음 기능으로 넘어감
핵심 요청 → 확인 → 저장을 기능마다 반복함.

내 과제에 기능 더하기

4.1 내 과제의 기능 목록 만들기

PRD.md의 완료 조건을 읽고, 아직 없는 기능을 작은 단위로 나눠줘.
- 기능 하나는 10분 안에 만들고 확인할 수 있는 크기로 나눠줘.
- 사용자에게 가장 중요한 기능부터 순서를 매겨줘.
- 표로 보여 줘: 순서 / 기능 이름 / 사용자 행동 / 확인 방법
- 아직 코드는 만들지 말아줘.

4.2 기능 하나씩 만들기

기능 하나만 만들어줘.
기능 이름: {무엇을 만들지}
사용자 행동: {사용자가 무엇을 하는지}
기대 결과: {그러면 무엇이 보이는지}
확인 방법: {내가 어떻게 눌러 확인할지}
다른 기능은 건드리지 말고, 다 만들면 내가 확인할 순서를 알려줘.

4.3 자주 쓰는 기능

필터 · Filter"단계 버튼을 누르면 그 단계만 보여 줘"
정렬 · Sort"날짜가 가까운 순으로 정렬해줘"
상세 보기 · Modal"항목을 누르면 자세한 내용을 팝업으로 보여 줘"
입력 폼 · Form"새 항목을 입력해 목록에 더하게 해줘"
합계 · Summary"위에 전체 개수와 합계를 카드로 보여 줘"
내보내기 · Export"지금 보이는 목록을 CSV로 내려받게 해줘"

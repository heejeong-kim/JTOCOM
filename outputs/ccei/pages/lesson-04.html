1.1 준비

  • 고치기 전에 지금 상태를 새 버전으로 저장하고 CHANGELOG.md에 한 줄 남김 (예: v04-PRD전)
  • 공공데이터포털(data.go.kr)에 회원가입하고 창업진흥원 K-Startup 조회서비스를 활용신청해 둠 (인증키가 동작하기까지 시간이 걸릴 수 있음)

1.2 PRD 기준으로 화면 다듬기

2교시에 말로 만든 화면을 버리지 않고, 3교시 PRD에 맞춰 고쳐 나감.

  1. ① PRD와 지금 화면 비교하기

    나는 코딩을 모르는 초보자야. 이 폴더의 PRD.md와 지금 만들어진 화면을 비교해줘.
표로 보여 줘: PRD 항목 / 지금 화면 / 고칠 점
아직 코드는 고치지 말고, 고칠 점을 중요한 순서로 정리만 해줘.

  2. ② PRD에 맞게 고치기

    방금 정리한 고칠 점을 PRD 기준으로 고쳐줘.
- 파일은 지금처럼 index.html, css/style.css, js/script.js, data/로 나눠 둬.
- 지금 잘 되는 기능은 그대로 둬.
- 고친 곳을 파일별로 짧게 알려 주고, 내가 확인할 순서도 알려줘.

  3. ③ 컴포넌트 이름으로 고쳐 보기

    "헤더(Header)에 서비스 이름을 크게 넣어줘""카드(Card)를 한 줄에 3개씩 보여 줘""버튼(Button) 색을 진한 초록으로 바꿔줘""빈 목록일 때 안내 문구를 보여 줘"
    지금 화면에서 {고칠 곳의 컴포넌트 이름}을(를) 고쳐줘.
바꾸고 싶은 점: {어떻게 바뀌면 좋을지}
다른 부분은 그대로 두고, 고친 곳만 알려줘.
2교시 화면이 없다면 · PRD로 첫 화면부터 만들기 
나는 코딩을 모르는 초보자야. 이 폴더의 PRD.md를 읽고, PRD에 적힌 화면 중 첫 화면 하나만 먼저 만들어줘.
- 파일은 역할별로 나눠줘: index.html(뼈대), css/style.css(꾸밈), js/script.js(동작), data/(데이터).
- 인터넷 연결이나 설치 없이, index.html을 더블클릭하면 바로 열리게 해줘.
- 아직 진짜 데이터가 없으니 가상의 예시 데이터 5개를 넣어줘.
- 휴대폰 화면에서도 깨지지 않게 해줘.
다 만들면 어떤 파일을 만들었는지, 어떻게 열어 보는지 3줄로 알려줘.
핵심 있는 화면을 PRD 기준으로 다듬고, 세부는 컴포넌트 이름으로 고쳐 달라고 말함.

2.2 함께 해 보기

  1. ① CSV 불러오기

    • support-programs.csv 가상 지원사업 200개

    내려받은 파일을 프로젝트의 data 폴더에 넣고 요청함.

    data 폴더에 support-programs.csv 파일을 넣었어.
이 파일의 지원사업 200개를 지금 화면의 예시 데이터 대신 보여 줘.
1. 먼저 파일에 어떤 열이 있는지, 몇 줄인지 알려줘.
2. index.html을 더블클릭해도 보이도록, 데이터를 data/data.js 파일로 바꿔서 연결해줘.
3. 창업 단계와 업종을 고르면 맞는 사업만 보이게 해줘.
4. 카드가 많으니 한 번에 12개씩 보여 주고, 아래에 '더 보기' 버튼을 넣어줘.
5. 원본 CSV 파일은 바꾸지 말아줘.

  2. ② JSON 들여다보기

    data/data.js에 들어간 데이터를 data/programs.json 파일로도 저장해줘.
그리고 나에게 쉬운 말로 알려줘.
1. JSON이 무엇인지 3줄로
2. CSV의 한 줄이 JSON에서는 어떻게 생겼는지, 사업 하나를 예로 들어서
3. 공공데이터 API가 왜 JSON으로 데이터를 보내 주는지
화면은 지금처럼 그대로 동작하게 해줘.

  3. ③ 로컬 스토리지에 저장하기

    카드마다 별표(☆) 버튼을 넣어서 관심 사업을 저장하게 해줘.
- 별표를 누르면 ★로 바뀌고, 새로고침하거나 창을 닫았다 열어도 그대로 남게 로컬 스토리지(LocalStorage)에 저장해줘.
- 화면 위에 '관심 사업만 보기' 버튼을 넣어줘.
- 저장된 값을 개발자 도구 어디에서 볼 수 있는지 쉬운 말로 알려줘.

  4. ④ 공공데이터 API 연결하기

    공공데이터포털의 '창업진흥원_K-Startup(사업소개,사업공고,콘텐츠 등)_조회서비스'로 실제 지원사업 공고를 받아 와서 화면에 '최신 공고' 탭으로 보여 주고 싶어.
인증키는 내가 .env 파일에 직접 넣을게. 인증키를 코드나 채팅에 쓰지 말아줘.

1. 시작하기 전에 필요한 파일과 내가 직접 할 일을 먼저 알려줘.
2. 브라우저에서 바로 부를 수 없으면, 이 컴퓨터에서 한 번 받아 와서 data/api-data.js로 저장하는 방법으로 해줘.
3. 받아 온 공고에서 사업명, 접수 기간, 신청 대상만 골라 카드로 보여 줘.
4. 실패하면 오류 내용을 쉬운 말로 알려줘.
    • 인증키는 .env 파일에만 두고, 화면·채팅·공유 파일에 붙여 넣지 않음
    • 다른 사람에게 폴더를 줄 때는 .env 파일을 빼고 줌
핵심 CSV로 넣고, JSON으로 이해하고, 로컬 스토리지에 남기고, API로 최신 데이터를 받아 옴.

3.2 내 과제에 연결하기

이 폴더의 PRD.md를 읽고, 내 과제의 첫 화면을 만들어줘. (PRD.md가 없다면 먼저 알려줘)
그다음 내 데이터를 연결하고 싶어.

내 데이터: {파일 이름 또는 쓰고 싶은 공공데이터 이름}
필요한 것: {예: 표로 보기, 즐겨찾기 저장, 최신 데이터 받아 오기}

CSV, JSON, 로컬 스토리지, 공공데이터 API 중 무엇이 필요한지 먼저 추천해 주고, 내가 고르면 하나씩 연결해줘.
파일은 index.html, css/, js/, data/로 나눠 두고, 원본 파일은 바꾸지 말고, 인증키는 .env 파일에만 두게 해줘.
다른 방법 · 2교시에 뜯어본 서비스를 참고해 시작하고 싶을 때 열기 
나는 코딩을 모르는 초보자야. 내가 참고한 서비스를 바탕으로, 비슷한 문제를 해결하는 나만의 웹 서비스 첫 화면을 만들고 싶어.
참고 서비스의 이름·문구·로고·브랜드 디자인은 그대로 베끼지 말고, 사용자에게 필요한 기능과 유저 플로우만 참고해줘.

[참고한 서비스]
서비스: {서비스명 또는 URL}
분석 결과: {뜯어보기에서 받은 분석 결과를 그대로 붙여 넣기}

[내가 만들 서비스]
서비스 이름: {서비스 이름}
사용자: {누가 사용하는지}
해결할 불편: {어떤 문제를 줄일지}
사용자가 끝내려는 일: {핵심 행동 하나}

[참고 서비스에서 가져올 것]
레이아웃·컴포넌트: {필요한 화면 영역과 컴포넌트}
유저 플로우: {화면 → 화면 순서}
데이터 항목: {화면에 표시할 정보}

[만들기 조건]
- 만들기 전에 어떤 화면을 어떤 순서로 만들지 3줄로 먼저 알려주고 바로 만들어줘.
- 브라우저에서 바로 열리는 웹(HTML·CSS·JavaScript)으로 만들고, PC와 휴대폰 화면에서 모두 잘 보이게 해줘.
- 핵심 행동 하나가 작동하는 첫 결과물에 집중해줘.
- 실제 개인정보 대신 가상의 예시 데이터 5~10개를 넣어줘.
- 로그인, 실제 데이터 저장, 외부 API 연결은 하지 말고 화면 안의 예시 데이터로 동작하게 해줘.
- 버튼과 입력 기능을 직접 확인하고, 작동하지 않는 부분은 고쳐줘.
- 마지막에 파일을 여는 방법, 만든 기능, 다음에 추가하면 좋을 기능 1가지를 쉬운 말로 알려줘.

3.3 공공데이터로 연습하기

내 데이터가 아직 없다면 아래 파일로 연습함. 내려받은 뒤 이름을 district.csv, senior-center.xlsx처럼 짧은 영문으로 바꿔 data 폴더에 넣음.

  • 행정구역 현황.csv 한글 깨짐 · 숫자에 쉼표
  • 경로당 현황.xlsx 제목 줄이 여러 줄
data 폴더에 공공데이터 파일 {파일 이름}을(를) 넣었어.
1. 파일에서 손봐야 할 점(한글 깨짐, 여러 줄 제목, 숫자 속 쉼표 등)을 먼저 알려줘.
2. 정리한 데이터를 data/data.js로 만들어줘. 원본 파일은 그대로 둬.
3. 위에는 핵심 숫자 카드 3개, 아래에는 표를 보여 줘.
핵심 함께 해 본 네 가지 방법 중 내 과제에 필요한 것만 골라 연결함.

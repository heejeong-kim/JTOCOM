기본 프로젝트 만들기

1.1 준비

  • Codex에서 새 채팅을 열고, 프로젝트 선택에서 PRD.md가 저장된 폴더를 고름
  • 폴더에 PRD.md가 없다면 3교시 3.2 프롬프트로 먼저 만듦

1.2 PRD로 첫 화면 만들기

  1. ① 첫 화면 만들기

    나는 코딩을 모르는 초보자야. 이 폴더의 PRD.md를 다시 읽고, 작업 순서의 1단계를 시작해줘.
PRD에 적힌 화면 중 첫 화면 하나만 먼저 만들어줘.
- index.html, style.css, script.js 세 파일로 만들어줘.
- 인터넷 연결이나 설치 없이, index.html을 더블클릭하면 바로 열리게 해줘.
- 아직 진짜 데이터가 없으니 가상의 예시 데이터 5개를 넣어줘.
- 휴대폰 화면에서도 깨지지 않게 해줘.
다 만들면 어떤 파일을 만들었는지, 어떻게 열어 보는지 3줄로 알려줘.

  2. ② 컴포넌트 이름으로 고쳐 보기

    "헤더(Header)에 서비스 이름을 크게 넣어줘""카드(Card)를 한 줄에 3개씩 보여 줘""버튼(Button) 색을 진한 초록으로 바꿔줘""검색창(Search Bar)을 목록 위에 넣어줘""빈 목록일 때 안내 문구를 보여 줘"
    지금 화면에서 {고칠 곳의 컴포넌트 이름}을(를) 고쳐줘.
바꾸고 싶은 점: {어떻게 바뀌면 좋을지}
다른 부분은 그대로 두고, 고친 곳만 알려줘.
다른 방법 · 2교시에 뜯어본 서비스를 참고해 시작하고 싶을 때 열기 
나는 코딩을 모르는 초보자야. 내가 참고한 서비스를 바탕으로, 비슷한 문제를 해결하는 나만의 웹 서비스 첫 화면을 만들고 싶어.
참고 서비스의 이름·문구·로고·브랜드 디자인은 그대로 베끼지 말고, 사용자에게 필요한 기능과 유저 플로우만 참고해줘.

[참고한 서비스]
서비스: {서비스명 또는 URL}
분석 결과: {뜯어보기에서 받은 분석 결과를 그대로 붙여 넣기}

[내가 만들 서비스]
서비스 이름: {서비스 이름}
사용자: {누가 사용하는지}
해결할 불편: {어떤 문제를 줄일지}
사용자가 끝내려는 일: {핵심 행동 하나}

[참고 서비스에서 가져올 것]
레이아웃·컴포넌트: {필요한 화면 영역과 컴포넌트}
유저 플로우: {화면 → 화면 순서}
데이터 항목: {화면에 표시할 정보}

[만들기 조건]
- 만들기 전에 어떤 화면을 어떤 순서로 만들지 3줄로 먼저 알려주고 바로 만들어줘.
- 브라우저에서 바로 열리는 웹(HTML·CSS·JavaScript)으로 만들고, PC와 휴대폰 화면에서 모두 잘 보이게 해줘.
- 핵심 행동 하나가 작동하는 첫 결과물에 집중해줘.
- 실제 개인정보 대신 가상의 예시 데이터 5~10개를 넣어줘.
- 로그인, 실제 데이터 저장, 외부 API 연결은 하지 말고 화면 안의 예시 데이터로 동작하게 해줘.
- 버튼과 입력 기능을 직접 확인하고, 작동하지 않는 부분은 고쳐줘.
- 마지막에 파일을 여는 방법, 만든 기능, 다음에 추가하면 좋을 기능 1가지를 쉬운 말로 알려줘.
핵심 PRD를 기준으로 만들고, 마음에 안 드는 곳은 컴포넌트 이름으로 고쳐 달라고 말함.

2.1 데이터 파일 준비 규칙

표 모양이 깔끔할수록 AI가 데이터를 정확히 읽음.

규칙 1

첫 줄은 열 이름

좋은 예
사업명 · 대상 · 마감일
피할 것
제목 줄이 2~3줄로 합쳐진 표
규칙 2

한 칸에 값 하나

좋은 예
마감일 칸에 날짜만
피할 것
"12/31 (연장 가능)"처럼 섞기
규칙 3

개인정보는 지우기

지울 것
이름, 연락처, 주소, 주민번호
대신
가짜 이름이나 번호로 바꾸기
규칙 4

파일 이름은 짧게

좋은 예
programs.csv
피할 것
띄어쓰기·괄호가 많은 이름

2.2 CSV · 엑셀 불러오기

CSV(Comma-Separated Values)는 쉼표로 칸을 나눈 표 파일이고, 엑셀(.xlsx)도 같은 방법으로 쓸 수 있음.

프로젝트 폴더에 {파일 이름.csv 또는 .xlsx} 파일을 넣었어.
이 파일의 데이터를 지금 화면의 예시 데이터 대신 보여 주고 싶어.

1. 먼저 파일을 열어서 어떤 열이 있는지, 몇 줄인지 알려줘.
2. 한글이 깨지거나 제목 줄이 여러 줄이면 고쳐서 읽어줘.
3. index.html을 더블클릭해도 보이도록, 데이터를 data.js 파일로 바꿔서 연결해줘.
4. 원본 파일은 바꾸지 말아줘.

화면에 보여 줄 열: {보여 줄 열 이름들}
핵심 먼저 예시 데이터로 화면을 만들고, 그다음 진짜 데이터로 바꿔 끼움. 원본 파일은 그대로 둠.

공공데이터 활용

3.1 파일데이터와 오픈API

공공데이터포털(data.go.kr)에는 내려받는 파일데이터와, 프로그램이 직접 받아 오는 오픈API(Open API)가 있음.

추천 · 오늘 실습

파일데이터 (CSV · 엑셀)

내려받아 폴더에 넣으면 바로 씀

장점
신청 없이 바로 쓰고, 인터넷이 없어도 열림
단점
최신 값으로 바꾸려면 다시 내려받아야 함
심화

오픈API

주소로 요청하면 최신 데이터를 보내 줌

장점
항상 최신 데이터를 보여 줌
단점
활용 신청과 인증키(API Key)가 필요하고 승인까지 시간이 걸림

3.2 연습용 공공데이터로 해 보기

내 데이터가 아직 없다면 아래 파일로 연습함. 내려받은 뒤 이름을 district.csv, senior-center.xlsx처럼 짧은 영문으로 바꿔 프로젝트 폴더에 넣음.

  • 행정구역 현황.csv 한글 깨짐 · 숫자에 쉼표
  • 경로당 현황.xlsx 제목 줄이 여러 줄
프로젝트 폴더에 공공데이터 파일 {파일 이름}을(를) 넣었어.
이 데이터로 한눈에 보는 현황 화면을 만들고 싶어.

1. 파일에서 손봐야 할 점(한글 깨짐, 여러 줄 제목, 숫자 속 쉼표 등)을 먼저 알려줘.
2. 정리한 데이터를 data.js로 만들어줘. 원본 파일은 그대로 둬.
3. 위에는 핵심 숫자 카드 3개, 아래에는 표를 보여 줘.
4. 표 제목을 누르면 정렬되게 해줘.

3.3 오픈API를 쓸 때 지킬 것

  • 인증키(API Key)는 비밀번호처럼 다루고 화면·채팅·공유 파일에 붙여 넣지 않음
  • 인증키가 들어간 파일은 공개 저장소에 올리지 않음
  • 처음에는 파일데이터로 화면을 완성하고, API는 다음 단계로 바꿔 끼움
핵심 파일데이터로 먼저 완성하고, 오픈API는 인증키를 지키며 다음 단계에서 바꿔 끼움.

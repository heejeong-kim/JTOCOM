1.1가상 데이터 넣기

PRD에 적힌 가상 공고·입주기업과 공휴일 파일을 data 폴더에 연결합니다.

  • startup-programs.csv 가상 공고 30건
  • startups.csv 가상 입주기업 10곳
  • holidays.csv 공휴일 2026.12~2027.3
  • 세 파일을 내려받아 data 폴더에 넣습니다
  • 프롬프트를 보내고 AI가 알려 준 열과 줄 수를 확인합니다
  • 폴더에 data/data.js가 생겼는지 봅니다
data 폴더에 startup-programs.csv(공고 30건), startups.csv(입주기업 10곳), holidays.csv(공휴일)를 넣었어.
1. 먼저 세 파일에 어떤 열이 있는지, 몇 줄인지 알려줘.
2. 더블클릭으로 열어도 읽히게 세 파일을 data/data.js 하나로 바꿔줘.
3. 열 이름이나 날짜 표기가 PRD.md와 다르면 맞추고 무엇을 맞췄는지 알려줘.
4. 원본 CSV 파일은 바꾸지 말아줘.

1.2화면 3개 뼈대 만들기

PRD의 화면 3개와 화면 이동을 먼저 만듭니다.

  • startup-radar 프로젝트에서 프롬프트를 보냅니다
  • index.html을 더블클릭해 세 화면을 오가 봅니다
  • 창을 휴대폰 크기로 줄여도 깨지지 않는지 봅니다
이 폴더의 PRD.md를 읽고, 화면 3개(레이더 · 공고 상세 · 주간 브리핑)의 뼈대와 화면 이동을 만들어줘.
- 레이더에는 data/data.js의 공고 30건을 카드로 보여 줘.
- 카드를 누르면 공고 상세로, 상단 탭으로 레이더와 주간 브리핑을 오가게 해줘.
- 검색·스크랩 같은 기능은 아직 넣지 말고, 화면과 이동만 먼저 만들어줘.
- 휴대폰 화면에서도 깨지지 않게 해줘.

2.2키워드 검색·스크랩 저장하기

관심 키워드로 공고를 찾고, 키워드와 스크랩을 로컬 스토리지에 남깁니다.

  • 프롬프트를 보내고 키워드를 하나 추가해 봅니다
  • 카드의 별(★)을 눌러 스크랩해 봅니다
  • 새로고침해도 키워드와 스크랩이 남는지 봅니다
레이더 왼쪽에 '관심 키워드'를 넣는 칸과 추가·삭제 버튼을 만들어줘.
- 등록한 키워드 중 하나라도 공고명·키워드·지원 내용에 들어가면 그 공고만 보여 주고, 맞은 키워드는 색으로 표시해줘.
- 키워드가 없으면 전체 공고를, 결과가 없으면 안내 문구를 보여 줘.
- 카드의 별(★)을 누르면 스크랩되게 해줘.
- 키워드와 스크랩은 새로고침해도 남게 로컬 스토리지(LocalStorage)에 저장하고, 개발자 도구 어디에서 볼 수 있는지 쉬운 말로 알려줘.

2.3D-day와 준비 마감 계산하기

공휴일 파일로 D-day와 내부 준비 마감을 계산합니다.

  • 프롬프트를 보냅니다
  • 카드의 D-day와 준비 마감을 확인합니다
  • 12/25 앞뒤로 끝나는 공고의 준비 마감이 공휴일을 건너뛰는지 봅니다
공고 카드마다 D-day와 내부 준비 마감을 보여 줘.
- D-day는 한국 날짜 기준 '접수 마감일 − 오늘'로 계산하고, 당일은 D-day, 지난 공고는 '마감'으로 보여 줘.
- 접수 마감일은 공휴일 때문에 바꾸지 말아줘.
- 내부 준비 마감은 접수 마감일에서 3영업일 전으로 하고, 주말과 공휴일 파일의 날짜는 빼고 계산해줘.
- 마감이 가까운 순서로 정렬해줘.

2.4JSON으로 주고받기

관심 키워드와 스크랩을 JSON 파일로 내보내고 불러옵니다.

  • '내보내기'를 눌러 파일을 받아 봅니다
  • 받은 radar-briefing.json을 열어 모양을 봅니다
  • 시크릿 창에서 '불러오기'로 같은 내용이 보이는지 봅니다
동료에게 넘길 수 있게 '내보내기'와 '불러오기' 버튼을 만들어줘.
- 내보내기를 누르면 관심 키워드와 스크랩한 공고를 radar-briefing.json 파일로 내려받게 해줘.
- 불러오기로 그 파일을 고르면 같은 내용이 화면에 보이게 해줘.
- JSON이 무엇인지 3줄로, 공고 하나가 JSON에서 어떻게 생겼는지 예를 들어 쉬운 말로 알려줘.
[옵션] K-Startup 공고 API로 실제 공고 받아 오기
공공데이터포털의 'K-Startup 사업공고' API로 지금 모집 중인 지원사업 공고를 받아 와서 레이더에 보여 주고 싶어.
인증키는 내가 .env 파일에 직접 넣을게.

1. 시작하기 전에 필요한 파일과 내가 직접 할 일을 먼저 알려줘.
2. 인증키가 화면에 드러나지 않도록, 이 컴퓨터에서 대신 불러 주는 작은 서버(server.js)로 만들어줘.
3. 받아 온 공고를 가상 공고 대신 보여 주고, 실패하면 가상 공고로 보여 줘.
4. 실패하면 오류 내용을 쉬운 말로 알려줘.
  • 인증키는 .env 파일에만 두고, 화면·채팅·공유 파일에 붙여 넣지 않습니다
  • 브리핑 파일이나 폴더를 줄 때는 .env 파일을 빼고 줍니다
핵심 키워드·스크랩은 로컬 스토리지에 남기고, 마감은 공휴일 파일로 계산하고, 기록은 JSON으로 주고받습니다.

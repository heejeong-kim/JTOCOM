점검

Codex 셋팅 확인

1.1 Codex 앱 설치·실행

  • 노트북에 Codex 앱이 설치되어 있음 (macOS·Windows)
  • Codex 앱을 열면 첫 화면이 정상적으로 보임

1.2 ChatGPT 계정 로그인

  • 첫 화면에서 Continue with ChatGPT로 로그인함
  • 교육용으로 안내받은 유료 ChatGPT 계정으로 로그인되어 있음
  • 로그인 후 메시지 입력창이 보임
Codex 시작하기 공식 안내 ↗
주의 로그인이 안 되거나 사용할 수 없는 계정이라고 나오면 혼자 해결하지 말고 바로 손을 들어 강사·보조강사에게 알림.
점검

로컬 프로젝트 폴더 확인

2.1 실습 폴더 만들기

1단계

Codex 폴더

문서(Documents) 안에 모든 실습을 모아 둘 폴더

Mac
문서 › Codex
Windows
문서 › Codex
2단계

vibe-practice 폴더

Codex 폴더 안에 오늘 실습용 폴더

Mac
문서 › Codex › vibe-practice
Windows
문서 › Codex › vibe-practice
3단계

실습 파일 넣기

나눠 준 CSV·엑셀 실습 파일이 있으면 이 폴더에 넣어 둠

확인
폴더 이름은 영문·숫자로, 띄어쓰기 없이

2.2 Codex에 폴더 연결

  • Codex에서 프로젝트 선택(Add project) 화면을 열고 vibe-practice 폴더를 선택함
  • 입력창 아래가 Local(로컬)로 선택되어 있음
  • 권한 설정은 기본값(Default permissions)을 그대로 둠

2.3 연결 확인하기

지금 연결된 폴더의 이름과 위치를 알려줘.
그리고 이 폴더 안에 hello.html 파일을 하나 만들어서, 화면 가운데에 '실습 준비 완료'라는 큰 제목이 보이게 해줘.
  • Codex가 알려 준 폴더 이름이 vibe-practice임
  • Finder(Mac)·파일 탐색기(Windows)에서 vibe-practice 폴더 안에 hello.html이 생김
  • hello.html을 더블클릭하면 브라우저에 실습 준비 완료가 보임
주의 Codex는 연결한 폴더 안에서만 작업함. 다른 폴더의 파일을 쓰려면 그 파일을 vibe-practice 폴더로 옮겨 둠.

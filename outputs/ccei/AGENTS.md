# AGENTS.md — 실무 중심 바이브코딩 교육 교안 사이트

이 폴더에서 AI가 작업할 때 지키는 규칙임. 무엇을 만들지(목적·사용자·사이트맵·교시별 구성·기능)는 `PRD.md`를 기준으로 함.

## 1. 폴더 구조

```
index.html               강의 커리큘럼(첫 화면)
pages/lesson-01~07.html  교시별 교안
css/style.css            첫 화면 스타일
css/lesson.css           교안 기본 스타일
css/lesson-theme.css     교안 덮어쓰기 스타일(새 스타일은 맨 아래에 추가)
js/                      동작 스크립트
assets/                  이미지·캡처
data/                    교안용 데이터
samples/                 수강생 배포용 샘플(support-guide.zip, startup-radar, skills)
PRD.md                   무엇을 만들지
AGENTS.md                어떻게 작업할지(이 파일)
_backup/                 날짜별 백업 + README.md 변경 이력(로컬에만 둠)
```

## 2. 작업 방식

- 요청한 부분만 고치고, 관련 없는 파일·문구는 건드리지 않음
- 같은 유형의 수정은 7개 교시 전체를 점검해 함께 맞춤
- 고친 뒤 PC 1600px · 태블릿 768px · 휴대폰 390px에서 가로 넘침·깨짐이 없는지 확인함
- 교안 구성·기능이 바뀌면 `PRD.md`를 함께 최신화하고, 규칙이 바뀌면 이 파일을 최신화함
- 백업: 그날 첫 수정 전에 `_backup/YYYY-MM-DD/`에 한 번만 백업함
- 변경 이력: 커밋마다 `_backup/README.md` 커밋 표 맨 위에 한 줄(시각 · 커밋 · 내용) 추가하고 "커밋 N건" 숫자를 올림
- 배포: GitHub `heejeong-kim/JTOCOM`의 `outputs/ccei`와 로컬 `03 webview` 폴더를 항상 같은 내용으로 맞춤
- 끝나면 바뀐 파일과 확인 방법을 짧게 알려 줌

## 3. 문장 규칙

- 교안 본문(설명·체크·핵심·용어 풀이)은 경어체("~합니다/~입니다"), 프롬프트만 반말
- `PRD.md`·`AGENTS.md` 같은 작업 문서는 "~함" 종결어미로 씀
- 소단원(x.x) 제목 바로 아래에는 짧은 안내 한 줄(`p.desc`)만 두고 다른 설명은 덧붙이지 않음
- 안내 문장은 한 문장 한 줄로 씀
- 단정·보장 표현("~의 전부임", "한 번에 나옴", "흔들리지 않음") 대신 경향으로 씀("~하기 쉽습니다", "~경우가 많습니다")
- 부가 설명(괄호 속 OS별 조작, 다른 교시 언급, 덧붙인 예시)은 넣지 않고 핵심 문장만 씀
- 제목·설명은 "서비스"로 쓰고, "웹/앱"은 1교시 2.1 웹과 앱 비교에서만 씀, 실제 결과물은 "웹"으로 씀
- 용어는 한국어 + 영문 병기, 1교시 표기를 기준으로 통일함
  - 레이아웃(Layout) / 컴포넌트(Component), "부품"은 쓰지 않음
  - IA(정보 구조) / 메뉴 구조도(Menu Tree) / 사이트맵(Sitemap)은 서로 다른 용어로 구분
  - 유저 플로우(User Flow), 데이터 명세서(Data Specification), 요청(Request)·응답(Response)
- 화면에 출처 문구를 넣지 않고, "공무원" 표현과 근거 없는 수치 추정은 쓰지 않음
- 예시에는 실제 개인정보·내부 자료 대신 가상 데이터만 씀

## 4. 프롬프트 규칙

- 용어를 모르는 완전 초보자 기준으로 쓰고, "1교시" 같은 수업 맥락 없이도 이해되게 씀
- 특정 기관 사이트가 아니라 어떤 서비스에나 쓸 수 있게 씀
- 3~7교시 프롬프트는 왼쪽 체크 3줄 + 오른쪽 프롬프트 창을 화살표로 연결(prompt-flow), 1·2교시는 그대로 둠
- 수강생 AGENTS.md(3교시 4.4)에 넣은 규칙(초보자 설명, 파일 구조, 더블클릭 실행, 요청한 것만 고치기, 개인정보·.env, 바뀐 파일·확인 방법, CHANGELOG, PRD.md 함께 고치기)은 4교시 이후 프롬프트에서 반복하지 않음
- 수강생 PRD에는 무엇을 만들지만 넣고, 파일 구조 같은 작업 규칙은 AGENTS.md에 둠
- 교안 패턴(3교시 기준): 섹션 제목 아래 필요하면 "시작 전" 박스 → 소단원(x.x)마다 안내 한 줄 + prompt-flow(체크 3줄+프롬프트) → 각자 채울 곳은 {} 자리 표시 + 아래 [참고] 레이더 예시(회색) → AI 결과는 [답변 예시](세이지 그린) → 섹션 끝 핵심 한 줄
- 버전 관리는 versions/ 폴더 복사 없이 CHANGELOG.md 이력만 씀(번호 · 날짜·시간 · 바꾼 내용 · 이유, 최신이 맨 위)

## 5. 교안 구성 규칙

- 콘텐츠 위계: 섹션 제목 > 소단원(번호 배지) > 소제목(왼쪽 막대) > 설명(블릿), 소단원 내용은 들여쓰기
- 번호 체계: 섹션 1. / 하위 1.1 / 3단계 ①
- 실습 섹션은 "준비" 체크 → 단계 프롬프트 순서, 섹션 끝에 "핵심" 한 줄
- 블릿은 동그라미로 통일, 프롬프트 준비 단계만 체크 아이콘(prompt-flow)
- 같은 줄 카드·박스는 배지·제목·설명·항목 줄 높이를 맞추고(subgrid), 잘리지 않게 함
- PRD 카드·진행 방식 카드도 프롬프트·블록과 같은 전체 폭
- 교안 하단에 이전·다음 교시 이동(1교시 이전·7교시 다음은 강의 커리큘럼)

# AGENTS.md — 실무 중심 바이브코딩 교육 교안 사이트

대전창조경제혁신센터 임직원 대상 「실무 중심 바이브코딩 교육」(2026-12-10, 7교시, 도구: OpenAI Codex) 교안 사이트에서 AI가 작업할 때 지키는 규칙임. 기획 내용은 `PRD.md`를 기준으로 함.

## 1. 폴더 구조

```
index.html            강의 커리큘럼(첫 화면)
pages/lesson-01~07.html  교시별 교안
css/style.css         첫 화면 스타일
css/lesson.css        교안 기본 스타일
css/lesson-theme.css  교안 덮어쓰기 스타일(새 스타일은 여기 맨 아래에 추가)
js/                   동작 스크립트
assets/               이미지·캡처
data/                 교안용 데이터
samples/              수강생 배포용 샘플(support-guide.zip, startup-radar, skills)
PRD.md                기획 문서(사이트맵·교시별 구성·콘텐츠 규칙·디자인 규칙)
AGENTS.md             이 파일
```

## 2. 작업 방식

- 요청한 부분만 고치고, 관련 없는 파일·문구는 건드리지 않음
- 같은 유형의 수정은 7개 교시 전체를 점검해 함께 맞춤
- 고친 뒤 데스크톱(1600px)·모바일(390px)에서 가로 넘침·깨짐이 없는지 확인함
- 수정이 끝나면 `PRD.md`의 해당 항목(교시별 구성·콘텐츠 규칙·디자인 규칙)을 함께 최신화함
- 그날 첫 수정 전에 `_backup/YYYY-MM-DD/`에 한 번 백업하고, 커밋마다 `_backup/README.md` 변경 이력 표 맨 위에 한 줄 추가함
- 끝나면 바뀐 파일과 확인 방법을 짧게 알려 줌

## 3. 문장 규칙

- 교안 본문(설명·체크·핵심·용어 풀이)은 경어체("~합니다/~입니다"), 프롬프트만 반말
- 소단원(x.x) 제목 바로 아래에는 짧은 안내 한 줄(`p.desc`)만 두고 다른 설명은 덧붙이지 않음
- 안내 문장은 한 문장 한 줄로 씀
- 단정·보장 표현("~의 전부임", "한 번에 나옴") 대신 경향으로 씀("~하기 쉽습니다")
- 부가 설명(괄호 속 OS별 조작, 다른 교시 언급, 덧붙인 예시)은 넣지 않음
- 용어는 한국어 + 영문 병기(예: 레이아웃(Layout), 컴포넌트(Component))
- 화면에 출처 문구를 넣지 않고, "공무원" 표현과 근거 없는 수치는 쓰지 않음
- 실제 개인정보·내부 자료는 예시에 넣지 않음(가상 데이터만 사용)

## 4. 디자인 규칙

- 글꼴: IBM Plex Sans KR(전 페이지)
- 주색: 테라코타 #c98269 / #a9654e, 콘텐츠에 파란색은 쓰지 않음
- 블릿은 동그라미로 통일, 프롬프트 준비 단계만 체크 아이콘(prompt-flow)
- 3~7교시 프롬프트는 왼쪽 체크 3줄 + 오른쪽 프롬프트 창(prompt-flow), 1·2교시는 그대로
- 섹션 유형 배지(block-step): 개념 테라코타 · 실습/함께 실습 초록 · 각자 실습 황토 · 참고 청록 · 정리 회갈색
- 카드 유형 라벨(kcard-tag): 플럼 배지, 공통 과제 블록(service-feature): 와인색 #8a2f4f
- 같은 줄 카드·박스는 그리드 높이를 맞추고(subgrid), 잘리지 않게 함
- 히어로 모션은 `prefers-reduced-motion` 설정 시 멈춤

## 5. 수업 프로젝트

- 2교시: `support-guide`(지원사업 추천 길잡이)
- 3교시부터: `startup-radar`(창업 지원사업 레이더 — 관심 키워드 → 공고 수집 → 매칭 → 알림 → 브리핑)
- 수강생은 CSV·로컬 스토리지·JSON 파일 실습, K-Startup API는 옵션(강사 시연용)
- API 키 신청 안내는 교안에 넣지 않음(강사가 오프라인으로 안내), 키는 `.env`에만 두고 공유·커밋하지 않음

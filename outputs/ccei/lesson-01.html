개념

바이브코딩이란

1.1 개념

코드를 한 줄씩 직접 쓰는 대신, 만들고 싶은 것을 말로 설명하면 AI가 코드를 작성하는 개발 방식임. 사람은 무엇을 원하는지 정확히 말하고, 결과를 확인해 고쳐 달라고 요청하는 역할을 맡음. 콜린스 사전은 바이브코딩을 '자연어로 지시한 AI가 컴퓨터 코드 작성을 돕도록 하는 것'으로 정의함.

1.2 기존 개발과의 차이

기존 개발완성까지 며칠 ~ 몇 주
  1. 기획 담당자아이디어
  2. 요청서 작성기능 정리
  3. 개발 대기일정 조율
  4. 개발자 코딩직접 작성
  5. 수정 요청다시 대기
바이브코딩첫 결과물까지 몇 분 ~ 몇 시간
  1. 나 (실무자)아이디어
  2. 말로 요청프롬프트
  3. AI가 코드 작성몇 초~몇 분
  4. 바로 확인·수정반복

1.3 발전 히스토리

  1. 2021~코드 자동완성

    개발자가 코드를 쓰면 AI가 다음 줄을 제안. 여전히 개발자 중심

  2. 2022 말~대화형 코드 생성

    ChatGPT 같은 챗봇에 말로 물어 코드를 받아 복사해 붙여 씀

  3. 2023~2024AI 코드 에디터

    편집기 안에서 AI가 여러 파일을 한 번에 읽고 고침

  4. 2025.02'바이브코딩' 용어 등장

    안드레이 카파시가 "코드의 존재조차 잊는" 개발 방식을 바이브코딩이라 부름. 같은 해 11월 콜린스 사전 '올해의 단어' 선정

  5. 2025~AI 코딩 에이전트

    Codex 등 에이전트가 계획 → 구현 → 테스트까지 스스로 진행, 사람은 지시·검토

  6. 2026 현재현업·공공으로 확산

    개발자가 아닌 실무자가 업무 도구와 서비스를 직접 만드는 단계

핵심 바이브코딩의 실력은 코딩 지식보다 무엇을 원하는지 정확히 말하는 힘에서 나옴.

3.1 실제 화면으로 서비스 뜯어보기

  1. ① 화면 각 부분의 이름 알기 · UI 용어

    첨부한 화면을 보고, 화면이 어떤 부분들로 나뉘어 있는지 위에서부터 차례로 알려줘.
각 부분을 서비스 만드는 사람들은 뭐라고 부르는지 이름도 알려주고, 나는 그런 이름을 하나도 모른다고 생각하고 쉬운 말로 설명해줘.
표(이름 | 화면의 어디 | 하는 일)로 정리해줘.

  2. ② 메뉴가 어떻게 나뉘었는지 보기 · 메뉴 구조도

    이 화면 맨 위의 메뉴를 보고, 이 사이트에 어떤 메뉴가 있고 각 메뉴 아래에 어떤 페이지가 들어 있을지 큰 것부터 작은 것 순서로 정리해줘.
이렇게 정리한 것을 서비스 만드는 사람들은 뭐라고 부르는지도 알려줘.

  3. ③ 사용자가 거쳐 가는 순서 보기 · 유저 플로우

    창업자가 이 사이트에 들어와서 지원사업 공고를 찾아 내용을 확인하기까지, 어떤 화면을 어떤 순서로 거치게 될지 알려줘.
화면 → 화면 형식으로 한 줄로 보여주고, 이런 순서를 정리한 것을 뭐라고 부르는지도 알려줘.

  4. ④ 화면에 담긴 정보 정리하기 · 데이터 명세서

    이 화면의 공지사항이나 사업공고 하나에는 어떤 정보들(예: 제목, 날짜)이 들어 있을지 정리해줘.
각 정보가 글자인지·날짜인지·숫자인지, 꼭 있어야 하는지도 표로 알려줘. 화면에서 안 보이는 건 '추측'이라고 표시해줘.
이런 표를 뭐라고 부르는지도 알려줘.

  5. ⑤ 화면 뒤에서 일어나는 일 알기 · 서비스 구조

    내가 이 사이트에서 공지사항 하나를 누르면, 눈에 안 보이는 뒤쪽에서는 어떤 일이 순서대로 일어나는지 아주 쉽게 설명해줘.
설명에 꼭 필요한 기본 용어는 내가 하나도 모른다고 생각하고 한 줄씩 뜻을 알려줘.

  6. ⑥ 꼭 필요한 것만 골라 계획 세우기 · MVP와 기획안

    이 사이트를 처음부터 아주 작게 만든다면, 꼭 있어야 하는 기능 3개만 골라줘.
그리고 지금까지 정리한 내용을 모아, 내가 AI에게 만들어 달라고 할 때 쓸 1장짜리 계획서로 정리해줘.
'작게 먼저 만드는 첫 버전'과 '이런 계획서'를 각각 뭐라고 부르는지도 알려줘.

  7. ⑦ 계획서로 직접 만들어 보기

    위 계획서를 보고 첫 화면을 웹 페이지로 만들어줘. HTML 파일 하나로 만들고, 내용은 가상 데이터로 채워줘.

3.4 만들고, 고치고, 공개하기

오류 메시지실행이 안 될 때 뜨는 빨간 안내 글. 그대로 복사해 AI에게 전달
개발자 도구 · 콘솔브라우저에서 F12로 여는 점검 창. 숨은 오류가 여기 보임
버전 · 체크포인트잘 될 때 저장해 두는 지점. 망가지면 이 지점으로 되돌림
로컬 · Local내 컴퓨터에서만 열리는 상태. 다른 사람은 못 봄
배포 · Deploy만든 서비스를 인터넷에 올려 누구나 쓸 수 있게 하는 일
URL서비스에 접속하는 인터넷 주소
도메인 · DomainURL 속 사이트 이름. 예: example.com
나는 코딩을 전혀 모르는 완전 초보자야. 만들던 화면에서 아래 빨간 오류 메시지가 떴어.
1. 이 오류가 무슨 뜻인지 전문 용어 없이 일상 비유로 한두 줄로 설명해줘. 꼭 써야 하는 용어가 있으면 바로 옆에 쉬운 뜻을 붙여줘.
2. 왜 생겼는지 가장 그럴듯한 이유를 하나만 알려줘.
3. 고치기 전에 무엇을 어떻게 바꿀지 먼저 말해주고, 내가 "좋아"라고 하면 그때 고쳐줘.
4. 고친 뒤에 내가 화면에서 무엇을 눌러 보면 제대로 됐는지 확인할 수 있는지 알려줘.

# 새 공고 추가

창업 지원사업 레이더(support-guide)에 새 공고를 넣고, 화면 데이터를 갱신하고, 맞는 입주기업을 알려 주고, 변경 이력을 남기는 절차임.

## 입력 형식

```
새 공고: 공고명 / 지원 분야 / 지역 / 창업 단계 / 접수 마감일 / 키워드
```

- 접수 마감일은 `YYYY-MM-DD` 형식임.
- 키워드는 `;`로 구분함. 예: `AI;실증`
- 신청 대상, 접수 시작일, 주관기관, 지원 내용은 사용자가 말하지 않으면 신청 대상은 `일반인`, 접수 시작일은 오늘, 나머지는 비워 둠.

예시:

```
새 공고: 대전 딥테크 실증 지원 / 기술개발 / 대전 / 7년미만 / 2027-01-20 / AI;실증
```

## 순서

1. **입력 확인**
   - 여섯 값(공고명, 지원 분야, 지역, 창업 단계, 접수 마감일, 키워드)이 모두 있는지 확인함.
   - 창업 단계는 `예비창업자`, `3년미만`, `7년미만` 중 하나인지 확인함.
   - 날짜 형식이 맞는지, 마감일이 오늘보다 뒤인지 확인함.
   - 맞지 않는 값이 있으면 추가하기 전에 사용자에게 한 번만 물어봄.
2. **중복 확인**: `data/startup-programs.csv`에 같은 공고명이 있으면 추가하지 않고 알려 줌.
3. **개인정보 확인**: 사람 이름, 연락처, 내부 자료로 보이는 값이 있으면 추가하기 전에 알려 주고 바꿀지 물어봄.
4. **CSV에 추가**
   - `data/startup-programs.csv` 맨 아래에 한 줄을 추가함.
   - 열 순서: 공고명, 지원 분야, 지역, 창업 단계, 신청 대상, 접수 시작일, 접수 마감일, 주관기관, 키워드, 지원 내용
   - 쉼표가 들어간 값은 큰따옴표로 감쌈.
   - 기존 줄과 파일 인코딩(UTF-8)은 바꾸지 않음.
5. **화면 데이터 갱신**: `data/data.js`를 CSV 기준으로 다시 만듦.
6. **맞는 입주기업 찾기**: `data/startups.csv`에서 지역·창업 단계·관심 키워드가 맞는 기업을 찾음.
7. **변경 이력 남기기**
   - CHANGELOG.md 맨 위에 다음 번호로 한 줄을 추가함: `번호 / 날짜·시간 / 새 공고 추가: {공고명} / 레이더에 공고 추가`
8. **결과 알리기**: 쉬운 말로 3줄 이내로 알려 줌.
   - 추가한 공고와 맞는 입주기업 수
   - 바뀐 파일
   - 확인 방법: 브라우저 새로고침 → 관심 키워드에 걸리는지 확인

## 하지 않는 것

- 기존 공고를 고치거나 지우지 않음.
- 화면 디자인이나 다른 기능을 바꾸지 않음.
- 원본 CSV의 열 이름이나 순서를 바꾸지 않음.

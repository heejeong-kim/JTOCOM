# 창업 지원사업 레이더 (완성 예시)

## 그냥 열기 (가상 데이터)
`index.html`을 더블클릭합니다. `data` 폴더의 가상 공고 30건·가상 입주기업 10곳·공휴일로 동작합니다.

## 강사 시연: K-Startup 실제 공고 불러오기
1. `.env.example`을 복사해 이름을 `.env`로 바꾸고, 공공데이터포털 인증키를 `DATA_GO_KR_KEY=`에 넣습니다.
2. 이 폴더에서 `node server.js`를 실행합니다. (Node.js 18 이상)
3. 브라우저에서 `http://localhost:3000`을 엽니다. 헤더에 `K-Startup 실시간`이 보이면 연결된 것입니다.

- 연결이 안 되면 자동으로 가상 데이터로 보여 줍니다.
- 요청 주소가 다르면 공공데이터포털 '활용신청 상세'에서 확인해 `.env`의 `KSTARTUP_URL`을 바꿉니다.
- `.env`는 화면·채팅·공유 파일에 붙여 넣지 않습니다.

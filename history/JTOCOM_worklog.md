## 2. 단계별 상세 기록

### 2-1. 초기 설계 (Lo-fi 와이어프레임)

**요청** — Figma 와이어프레임 설계
**확인 사항** — 랜딩페이지 / Lo-fi 충실도 / 화면정의서 + Figma 파일

Figma MCP 도구 호출이 3회 연속 승인되지 않아, 클릭 가능한 HTML 프로토타입 + 화면정의서로 방향 전환.

**대상 파일 (미사용)**
`https://www.figma.com/design/TRSLppVOU7dYfXa4V2crPV/중소기업`

**설계한 화면 6종**

| ID | 화면 | 주요 섹션 |
|---|---|---|
| HOM | 홈 | Hero / 고객사 / 서비스 3분할 / 프로세스 4단계 / 최근작업 / 성과지표 / 후기 / CTA |
| ABT | 브랜드 소개 | 페이지헤더 / 키비주얼 / 미션·비전 / 핵심역량 / 연혁 / 팀 |
| PRJ | 프로젝트 | 프로젝트 유형 4종 / 진행 방식 / 타임라인 / FAQ |
| PTF | 포트폴리오 | 필터·정렬 / 그리드 / 더보기 |
| PTD | 포트폴리오 상세 | 케이스 헤더 / 문제→접근→결과 / 관련 작업 |
| CNT | 컨택트 어스 | 문의 폼 / 연락처 / 약도 / FAQ |

**핵심 설계 판단 3가지**

- **프로젝트 vs 포트폴리오 역할 분리** — 프로젝트는 "제공하는 유형·산출물·기간", 포트폴리오는 "완료 작업물". 회사 홈페이지에서 사용자가 가장 많이 헤매는 지점이므로 카피에서 명시.
- **저작권·라이선스 카드를 본문에 배치** — FAQ가 아닌 본문 카드로 승격.
- **무한스크롤 대신 "더 보기" 버튼** — 접근성·SEO·푸터 도달률 모두 유리.

## 7. 트러블슈팅 기록

### 7-1. 컨테이너 쿼리 우선순위 문제

**증상** — 모바일 토글 시 햄버거 버튼이 표시되지 않음
**원인** — `.gnb__burger{display:none}` 기본 규칙이 컨테이너 쿼리 블록보다 **뒤에** 선언되어 동일 특정성에서 덮어씀
**해결** — 컨테이너 쿼리 내 셀렉터 특정성 상향 (`.gnb .gnb__burger`)

### 7-2. 해시 프래그먼트 자동 스크롤

**증상** — 모바일 초기 로드 시 히어로 상단이 헤더에 74px 가려짐
**원인** — `history.replaceState(null,'','#home')` 로 설정한 해시가 `id="home"` 요소와 일치해 브라우저가 프래그먼트로 자동 스크롤
**해결** — 라우팅 해시를 `#/home` 형태로 변경해 요소 ID와 충돌 제거

### 7-3. 다운로드 실패 (핵심)

**증상** — 전달한 파일이 반복적으로 다운로드되지 않음
**조사 과정**

1. 파일 무결성 검증 → ZIP 테스트 통과, HTML 파서 오류 0, 체크섬 일치
2. 표준 출력 폴더(`/mnt/user-data/outputs`)로 이전 후 재전송 → 실패
3. 확장자 우회(`.txt`), ZIP 압축, Google Drive 백업 경로 준비 → 실패
4. 파일시스템 점검 중 **작업 디렉터리가 오전 상태로 롤백**된 것을 발견

**원인** — 작업 컨테이너 상태가 되돌려지면서 생성했던 파일들이 서버에서 소실. 전달 링크는 남아있었으나 실제 파일이 없어 다운로드 불가.
**해결** — 전체 재구축 후 ZIP / HTML / .txt 3가지 형식으로 동시 전달
